SEW FA37DRN80M4 平行軸ヘリカルギヤモータ

ブランド: SEW-Eurodrive | 製品シリーズ: FAシリーズ (中空軸、平行軸)

SEW FA37DRN80M4 は、中空軸構造を採用した小型・高効率の産業用平行軸ヘリカルギヤモータです。高い機械効率、優れた熱安定性、省スペース設置の要求に応える設計となっており、軽量搬送コンベア、梱包機械、食品加工設備、各種自動化駆動システムに幅広く使用されています。

SEW 旧型モータの置き換え＆IE3 DRNへの更新ガイド

DT56S4 / DT56M4 / DT63K4 IE1 / 標準効率 DRN63MS4 / DRN63M4 IE3へ更新 0.18 kW - 0.25 kW F37減速機に対してフランジ寸法および軸径が1対1で一致。エネルギー損失を低減。
DT71D4 / DV71D4 IE1 / 標準効率 DRN71M4 IE3へ更新 0.37 kW - 0.55 kW 取付寸法が完全に同一。追加加工なしで直接置き換え可能。
DT80N4 / DV80N4 IE1 / 標準効率 DRN80M4 IE3へ更新 0.75 kW フランジおよび軸寸法が完全一致。FA37の標準的な組み合わせ。
DT90S4 / DV90S4 IE1 / 標準効率 DRN90S4 IE3へ更新 1.1 kW B5/B14アダプタとの高い互換性。現代のIE3基準に完全適合。
DT90L4 / DV90L4 IE1 / 標準効率 DRN90L4 IE3へ更新 1.5 kW - 2.2 kW F37、FA37、FAF37、FH37減速機ヘッドへの直接置き換えに対応。
DV100M4 / DRE100M4 IE1 / IE2 効率 DRN100LS4 / DRN100L4 IE3へ更新 2.2 kW - 3.0 kW F37シリーズの最大出力構成。従来のDV100M4をスムーズに置き換え。

選定および機器更新に関する技術ノート

当社は、SEW-Eurodrive F37シリーズ製品全般の駆動ソリューションおよび置換用技術提案を専門としています。脚取付実軸（F37）、キー溝付き中空軸（FA37）、B5出力フランジ（FAF37 / FF37）、シュリンクディスク接続（FH37）、キーレス締結システム TorqLOC®（FT37）など、すべての機械的構成において、IE3規格の高効率DRNシリーズモータ（DRN63M4〜DRN100L4）を事前組込の上ご提供可能です。

DT56、DT63、DT71、DT80、DV90 などの旧型モータを使用している既存設備を更新する際、IE3 DRNモータへ変更することで100%の寸法互換性が確保され、運転温度の低下と電気代の削減に大きく貢献します。現在お使いの機器のSEWシリアル番号または銘板写真（ブレーキBE、熱保護センサTF、逆止装置RS などのオプションを含む）をお送りいただければ、当社のエンジニアチームが100%正確な置換仕様と最適な見積をご案内いたします。
