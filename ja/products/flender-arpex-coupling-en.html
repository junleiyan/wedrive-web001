Flender ARPEX ARN-6 NEN 165-6 フレキシブルディスクカップリング

ブランド: Flender GmbH | シリーズ: ARPEX ねじり剛性オールスチールディスクカップリング (ARN-6 / ARN-8 / ARN-10 / ARS-6)

Flender ARPEX ARN-6 NEN 165-6 は、高精度、高ねじり剛性、および**完全なバックラッシフリー（100% backlash-free）**の動力伝達を実現するために設計された、業界標準の高性能オールスチールフレキシブルディスクカップリングです。高張力ステンレスバネ鋼ディスクパック（プレートパック）を採用しており、摺動部品を一切使用することなく、弾性変形のみで偏角・偏심・軸方向の軸芯ズレ（ミスアライメント）を補正します。**完全メンテナンスフリー**、摩耗なし、アライメント許容値内での半永久的な耐用年数、および極温耐性（-270℃〜+280℃）を備えており、最新の高性能ラインである **ARN-6、ARN-8、ARN-10** シリーズをはじめ、古典的な **ARS-6、ARC-8、ARP-6、ARW-4/6、ART-6** シリーズに至るまで、92 Nm から 2,000,000 Nm までの広いトルク範囲で展開されています。抄紙機、渦巻ポンプ、コンプレッサー、ターボ機械、試験機、風力発電、発電機セット、船舶推進装置などに幅広く採用されています。

専門技術調達 ＆ リプレイスエンジニアリングノート

当社は、Flender ARPEX オールスチールディスクカップリングファミリー全体の総合的な技術調達およびカスタム軸穴加工ソリューションの提供を専門としています。標準の中間スペーサーカップリング（ARN-6 / ARS-6 NENタイプ）、ロングスペーサーポンプドライブ（NHNタイプ）、キーレスシュリンクハブ（BEN / BHNタイプ）、省スペース型近接設計（CECタイプ）、あるいは API 610/671 ターボ機械用カップリング（ARP-6 NAN / MCEタイプ）のいずれであっても、すべてのハブはお客様の仕様に合わせて精度高く軸穴加工（キー溝、スプライン、テーパー穴など）を施して出荷可能です。

摩耗したギアカップリングや旧型の ARS-6 / ARC-8 ユニットを更新する際、現行の ARPEX ARN シリーズへアップグレードすることで、1対1の寸法互換性を維持しながら、定期的な潤滑や日常メンテナンスの手間を完全に排除できます。軸径、軸端間距離（DBSE）、回転数、およびモーター出力を御連絡いただければ、当社のエンジニアリングチームが100%適合する仕様選定と見積もりを作成いたします。
