SEW FA27DRN71M4 平行軸ヘリカルギアモータ

ブランド: SEW-Eurodrive | シリーズ: FAシリーズ（平行軸・ホローシャフト）

SEW FA27DRN71M4 は、中空軸（ホローシャフト）構造を採用した超薄型・小型の産業用平行軸ヘリカルギアモータです。高い機械効率、優れた耐熱性、狭小スペースへの設置ニーズに合わせて設計されており、小型搬送コンベヤ、攪拌機、包装機械、自動組み立てラインなどの駆動部に広く利用されています。

旧型SEWモータ更新＆IE3 DRNアップグレードガイド

F27減速機に搭載されている旧型のSEWモータ（DT、DV、DRS、DREシリーズ）は、最新のIE3 プレミアム効率DRNモータへスムーズに更新可能です。1対1の置き換えについては、以下の相互参照表をご確認ください：

旧型モータ型式（生産終了） 効率クラス 現行IE3代替モータ型式 定格出力 (kW) 機械的互換性・更新時の注意事項
DT56S4 / DT56M4 / DT63K4 IE1 / 標準効率 DRN63MS4 / DRN63M4 IE3へ更新 0.12 kW - 0.25 kW F27減速機へのフランジ・軸寸法が完全一致。エネルギー損失を大幅低減。
DT71D4 / DV71D4 IE1 / 標準効率 DRN71M4 IE3へ更新 0.37 kW - 0.55 kW 取付寸法が同一のため、そのまま直接入れ替えが可能。
DT80N4 / DV80N4 IE1 / 標準効率 DRN80M4 IE3へ更新 0.75 kW フランジおよび軸径寸法が完全同一。FA27の標準構成。
DT90S4 / DV90S4 IE1 / 標準効率 DRN90S4 IE3へ更新 1.1 kW B5/B14アダプタの互換性を維持。最新のIE3基準に完全適合。
DT90L4 / DV90L4 IE1 / 標準効率 DRN90L4 IE3へ更新 1.5 kW F27シリーズの最大出力構成。旧型DV90L4をそのままリプレース可能。

エンジニアリング選定＆更新設計ノート

当社は、SEW-Eurodrive F27シリーズ全般の完全駆動パッケージおよび技術的なリプレースメントソリューションの提供を専門としています。脚取付ソリッドシャフト仕様（F27）、キー溝付き中空軸仕様（FA27）、B5出力フランジ仕様（FAF27 / FF27）、シュリンクディスク締結仕様（FH27）、あるいはキーレスTorqLOC®固定システム（FT27）まで、あらゆる機械的デザインを最新のIE3 DRNシリーズモータ（DRN63M4〜DRN90L4）とあらかじめ組み合わせてご供給いたします。

生産終了となった旧型の DT56、DT63、DT71、DT80、DV90 モータが搭載された既存設備のリプレース時、IE3 DRNモータへ更新することで、取り付け寸法を100%維持したまま、運転温度の低下と電気代の大幅な削減を実現できます。既存SEW製品の銘板コードやシリアル番号（BEブレーキ、TFサーミスタ、RS逆転防止構造などのオプション情報含む）をお送りいただければ、当社のエンジニアリングチームが100%互換性のある代替仕様書とお見積りを作成いたします。
