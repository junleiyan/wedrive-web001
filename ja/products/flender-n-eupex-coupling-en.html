Flender N-EUPEX Type A 160 弾性ピンカップリング

ブランド: Flender GmbH | シリーズ: N-EUPEX ＆ N-EUPEX DS 弾性ピン＆ブッシュカップリング (サイズ 58 〜 710)

Flender N-EUPEX Type A 160 は、産業用動力伝達において世界中で最も広く採用されている3ピース構造の弾性ピン＆ブッシュ（ラバー）カップリングです。軸の芯 deviation（偏角、偏心、軸方向変位）を吸収しながら、ねじり振動や衝撃荷重を効果的に減衰するように設計されています。Type Aの3ピース構造により、駆動機器や従動機器を移動させることなく弾성ラバーブッシュの交換が可能です。サイズ58から710までの23種類の標準サイズをラインナップし、19 Nmから85,000 Nmの定格トルクに対応します。N-EUPEXカップリングは、NBRまたはTPUの弾性パックを備えたフェイルセーフな鋳鉄構造を特徴とし、ポンプ、ファン、ベルトコンベア、コンプレッサー、粉砕機、クレーン設備などに幅広く使用されています。

専門技術調達 ＆ 軸穴追加工エンジニアリングノート

当社は、Flender N-EUPEX および N-EUPEX DS カップリングファミリー全体の技術調達およびカスタム軸穴加工ソリューションを専門としています。メンテナンス性に優れた3ピースカップリング（N-EUPEX Type A 110 〜 710）、コンパクトな2ピースカップリング（Type B 58 〜 710）、ブレーキディスク/ドラム仕様（Type D / Type E）、ポンプ用スペーサースリーブ（Type H / Type P）、あるいは遮断型カップリング（N-EUPEX DS）のいずれであっても、すべてのハブにお客様ご指定の軸穴径、キー溝、テーパー穴、スプライン加工を精密に追加工して供給可能です。

既存設備のラバーブッシュ交換の際には、標準NBR 80 Shore A、高荷重用NBR 90 Shore A、および耐熱TPUグレードの純正 Flender N-EUPEX エラストマーパックを常時在庫しております。カップリングサイズ、軸径、運転条件をお知らせいただければ、当社のエンジニアリングチームが100%適合するリプレイス仕様をご提案いたします。
