کوپلینگ دیسکی انعطاف‌پذیر Flender ARPEX ARN-6 NEN 165-6

برند: Flender GmbH | سری: کوپلینگ‌های دیسکی تمام‌فولادی و سخت در برابر پیچش ARPEX (ARN-6 / ARN-8 / ARN-10 / ARS-6)

کوپلینگ Flender ARPEX ARN-6 NEN 165-6 یک کوپلینگ دیسکی انعطاف‌پذیر تمام‌فولادی شاخص با کارایی بالا است که برای انتقال قدرت با دقت بالا، سخت در برابر پیچش و ۱۰۰٪ بدون لق زدن (Zero Backlash) طراحی شده است. با استفاده از بسته‌های دیسک (پک‌های ورقه‌ای) از جنس فولاد ضدزنگ فنری با مقاومت بالا، ARPEX ARN-6 انحرافات زاویه‌ای، شعاعی و محوری شفت را صرفاً از طریق انعطاف‌پذیری الاستیک و بدون قطعات سایشی یا کشویی جبران می‌کند. این کوپلینگ با مزایایی همچون **عدم نیاز به نگهداری و تعمیرات**، عملکرد بدون استهلاک، طول عمر نامحدود در محدوده هم‌راستایی و مقاومت در برابر دمای فوق‌العاده بالا یا پایین (۲۷۰- درجه سانتی‌گراد تا ۲۸۰+ درجه سانتی‌گراد)، در تمام خطوط تولید اصلی متناسب با نیاز صنایع در دسترس است — از جمله سری‌های جدید با کارایی بالا **ARN-6, ARN-8, ARN-10** و سری‌های کلاسیک **ARS-6, ARC-8, ARP-6, ARW-4/6, ART-6** — با ظرفیت گشتاور از ۹۲ نیوتن‌متر تا ۲,۰۰۰,۰۰۰ نیوتن‌متر. این کوپلینگ‌ها به طور گسترده در ماشین‌آلات کاغذسازی، پمپ‌های سانتریفیوژ، کمپرسورها، توربوماشین‌ها، استندهای تست، توربین‌های بادی، ژنراتورها و سیستم‌های رانش دریایی استفاده می‌شوند.

ماتریس ساختار مدولار سری Flender ARPEX

راهنمای جامع خط تولید کوپلینگ‌های دیسکی انعطاف‌پذیر تمام‌فولادی Flender ARPEX. سری‌های مورد پشتیبانی، انواع ساختار، محدوده گشتاور و استانداردهای کاربردی در صنایع خاص را بررسی کنید:

سری کوپلینگ و کاربرد اصلی سایزهای پوشش داده‌شده گشتاور نامی (نیوتن‌متر) انواع ساختار استاندارد
ARPEX ARN-6 / ARN-8 / ARN-10 (بهینه‌شده برای گشتاور بالا) 100-6 تا 610-10 (۲۴ سایز) ۱,۲۰۰ تا ۱,۴۵۰,۰۰۰ NEN / NHN (اسپیسر استاندارد و بلند)
سری ARPEX ARS-6 (مدولار عمومی صنعتی) 78-6 تا 340-6 (۱۰ سایز) ۹۲ تا ۳۲,۰۰۰ NEN / NHN / MNN / MHN
توپی‌های قفل‌‌کننده بدون خار ARPEX (BEN / BHN / BMN) 78-6 تا 340-6 (۱۰ سایز) ۹۲ تا ۳۲,۰۰۰ BEN / BHN / BMN / BMH (توپی بدون خار)
سری ARPEX ARC-8 (صنایع سنگین و نورد) 210-8 تا 850-8 (۱۴ سایز) ۱۲,۰۰۰ تا ۲,۰۰۰,۰۰۰ NEN / NHN / BNN (سیستم‌های محرکه نورد سنگین)
سری ARPEX ARP-6 (توربوماشین‌ها و API 610 / API 671) 105-6 تا 325-6 (۹ سایز) ۱,۰۰۰ تا ۳۰,۰۰۰ NAN / MCE (منطبق با استانداردهای پمپ API)

راهنمای جایگزینی کوپلینگ‌های قدیمی و ارتقا به ARPEX

کوپلینگ‌های دیسکی قدیمی یا کوپلینگ‌های دنده‌ای فرسوده در پمپ‌های پرسرعت و توربوماشین‌ها را می‌توان به راحتی با کوپلینگ‌های دیسکی تمام‌فولادی Flender ARPEX جایگزین کرد. جدول معادل‌سازی ۱ به ۱ زیر را جهت جایگزینی ببینید:

سری / تیپ کوپلینگ قدیمی مکانیزم کوپلینگ مدل معادل فعلی ARPEX ظرفیت گشتاور نکات مهندسی جایگزینی و تطبیق ابعادی
قدیمی ARS-6 تیپ NEN 165-6 پک دیسکی کلاسیک ARPEX ARN-6 تیپ NEN 165-6 ارتقا به ARN ۴,۸۰۰ نیوتن‌متر تطبیق کاملاً دقیق ۱ به ۱ فلنج و اسپیسر DBSE. تراکم گشتاور بالاتر.
قدیمی ARS-6 تیپ NHN 195-6 اسپیسر بلند کلاسیک ARPEX ARN-6 تیپ NHN 190-6 ارتقا به ARN ۷,۵۰۰ نیوتن‌متر منطبق با فاصله بین دو سر شفت (DBSE) در پمپ‌های استاندارد ANSI/ISO.
کوپلینگ‌های دنده‌ای با روانکاری (ZAPEX) غلاف / دنده قوس‌دار سری ARPEX ARN-6 / ARC-8 بدون نگهداری تا ۲,۰۰۰,۰۰۰ نیوتن‌متر حذف کامل گریس‌کاری و سایش دندانه‌های چرخ‌دنده.
کوپلینگ‌های پنجه‌ای / انگشتی الاستومری قطعه واسط لاستیکی flex سری ARPEX ARS-6 / ARN-6 سخت در برابر پیچش ۹۲ تا ۳۲,۰۰۰ نیوتن‌متر انتقال قدرت سخت بدون لق زدن و مقاوم در برابر دماهای بسیار بالا.
سیستم‌های محرکه پمپ فرآیندی API 610 پک دیسکی استاندارد ARPEX ARP-6 تیپ NAN / MCE منطبق با API ۱,۰۰۰ تا ۳۰,۰۰۰ نیوتن‌متر دارای صفحات محافظ ضد پرتاب دیسک و بالانس دینامیکی کارخانه‌ای.

نکات تخصصی انتخاب و مهندسی جایگزینی

ما در زمینه تامین فنی و ماشین‌کاری سفارشی برای تمام مدل‌های خانواده کوپلینگ‌های دیسکی تمام‌فولادی Flender ARPEX تخصص داریم. چه خط انتقال قدرت شما نیازمند کوپلینگ با اسپیسر واسطه استاندارد باشد (ARN-6 / ARS-6 تیپ NEN)، چه اسپیسر بلند برای پمپ‌ها (تیپ NHN)، توپی‌های قفل‌کننده بدون خار (تیپ BEN / BHN)، طرح‌های فشرده برای فضاهای محدود (تیپ CEC) یا کوپلینگ‌های توربوماشین استاندارد API 610/671 (ARP-6 تیپ NAN / MCE)، تمامی توپی‌ها می‌توانند با دقت بالا تحت ماشین‌کاری داخل سوراخ شفت، جای خار سفارشی، اسپلین یا سوراخ مخروطی قرار گیرند.

هنگام بازسازی یک سیستم موجود دارای کوپلینگ‌های دنده‌ای فرسوده یا واحدهای قدیمی‌تر ARS-6 / ARC-8، ارتقا به سری فعلی ARPEX ARN باعث تطبیق ابعادی دقیق ۱ به ۱ شده و نیاز به روانکاری دوره‌ای و نگهداری مداوم را به طور کامل برطرف می‌سازد. کافی است قطر شفت‌ها، فاصله بین دو سر شفت (DBSE)، سرعت کاری و توان موتور را به ما اعلام کنید تا تیم مهندسی ما مشخصات دقیق و پیشنهاد قیمت منطبق را ارائه دهد.
