Pompes à vide Busch - Désignation du type

L'exemple suivant montre la structure de la désignation de type modulaire Busch :

Exemple : R5 RA 0250 D
R5 Série de produits Busch (ex : R5 = Palettes rotatives, MINK = Becs, COBRA = Vis sèches)
RA Version de conception / Application :
  • RA = Version robuste standard
  • PB = Version bloc compacte
  • RC = Conçu pour des tâches spécifiques de vide primaire
0250 Vitesse de pompage nominale : Indique le débit en m³/h (ex : 250 m³/h)
D Génération / Code de variante :
  • F, D, B, C = Indique la génération de conception évolutive ou la révision mécanique
