Mga Vacuum Pump ng Busch - Pagtatalaga ng Uri

Ipinapakita ng sumusunod na halimbawa ang istraktura ng modular na pagtatalaga ng uri ng Busch:

Halimbawa: R5 RA 0250 D
R5 Serye ng Produkto ng Busch (hal., R5 = Rotary Vane, MINK = Claw, COBRA = Dry Screw)
RA Bersyon ng Disenyo / Aplikasyon:
  • RA = Karaniwang matibay na bersyon
  • PB = Compact na bersyon ng block
  • RC = Idinisenyo para sa mga partikular na gawain sa rough vacuum
0250 Nominal na Bilis ng Pagbomba: Ipinapahiwatig ang rate ng daloy sa m³/h (hal., 250 m³/h)
D Henerasyon / Code ng Variant:
  • F, D, B, C = Ipinapahiwatig ang henerasyon ng ebolusyonaryong disenyo o mekanikal na rebisyon
