เกียร์อุตสาหกรรม Hansen (รุ่น P4 และ M4) และเกียร์ทดรอบงานหนัก

HANSEN P4 หลายสเตจ, HANSEN M4 ACC หอหล่อเย็น และชุดเกียร์ SUMITOMO-HANSEN รุ่นดั้งเดิม

เกียร์ทดรอบอุตสาหกรรม HANSEN และชุดเกียร์ทดแทน

อุตสาหกรรมและการใช้งานหนักที่รองรับ:

คอนเดนเซอร์ระบายความร้อนด้วยอากาศ (ACC) และหอหล่อเย็น, ปูนซีเมนต์และเหมืองแร่, เคมีภัณฑ์และเภสัชกรรม, เครื่องจักรก่อสร้าง, อุปกรณ์ท่าเรือและการเดินเรือ, อุตสาหกรรมโลหะ, แร่ธาตุและวัตถุดิบ, การสำรวจน้ำมันและก๊าซ, ระบบยกและรอกเครน, โรงไฟฟ้า, โรงงานเยื่อกระดาษและกระดาษ และระบบบำบัดน้ำเสีย

ด้านบนคือตารางข้อมูลทางเทคนิคและแพลตฟอร์มการเลือกรุ่นที่ครอบคลุมสำหรับชุดส่งกำลังอุตสาหกรรมงานหนัก HANSEN P4 และ M4 ACC

* หมายเหตุ: พิกัดกำลังมอเตอร์สูงสุดอ้างอิงจากมอเตอร์ไฟฟ้ากระแสสลับ 4 โพล ที่ความถี่ไฟฟ้า 50 Hz / 60 Hz WeDrive Power Transmission จัดจำหน่ายชุดเกียร์ทดแทนที่ติดตั้งแทนที่ได้ทันที (Drop-in Replacement) อะไหล่แท้ และชุดขับสมบูรณ์สำหรับระบบ Hansen Industrial Transmissions ทั่วโลก

การออกแบบชุดขับงานหนักแรงบิดสูงและพิกัดกำลังขาเข้า:

ข้อมูลจำเพาะทางเทคนิค: รูปแบบชุดเกียร์งานหนัก HANSEN P4 และ M4 ACC

รูปแบบการติดตั้งและการใช้งานเกียร์อุตสาหกรรม Hansen P4 และ M4 ACC

คู่มือการเลือกใช้งานอย่างครบถ้วนสำหรับเกียร์ทดรอบหลายสเตจ Hansen P4, เกียร์หอหล่อเย็น Hansen M4 ACC, ชุดขับสายพาน UniMiner และรูปแบบการติดตั้งเฉพาะทาง

ความน่าเชื่อถือที่พิสูจน์แล้วสำหรับชุดขับอุตสาหกรรมหนัก: ซีรีส์ Hansen P4 และ Hansen M4 ACC มอบความสามารถในการรับแรงบิดสูง (สูงสุด 552,000 N·m) พร้อมรูปทรงฟันเฟืองที่เหมาะสม เสื้อเกียร์แบบแยกส่วน และระบบระบายความร้อนประสิทธิภาพสูง ออกแบบมาเพื่อการติดตั้งทดแทนได้ทันทีในงานเหมืองแร่ ปูนซีเมนต์ การลำเลียงวัสดุ คอนเดนเซอร์ระบายความร้อนด้วยอากาศ และหอหล่อเย็น

หมวดหมู่รูปแบบ รายละเอียดการออกแบบและโครงสร้าง การใช้งานเป้าหมายและคำค้นหา
ชุดขับพร้อมมอเตอร์ / ฐานแท่นเครื่องรวม • ชุดฐานแท่นเครื่องรวม (Common Baseplate): ชุดมอเตอร์เกียร์ครบชุดติดตั้งบนแท่นเหล็กแข็งแรงพร้อมคัปปลิ้งยืดหยุ่น
• ชุดขับเพลาขวาง (เฟืองดอกจอกเฉียง): รูปทรงเพลาขวางกะทัดรัดพร้อมแท่นยึดมอเตอร์ด้านบนหรือด้านข้าง
• ชุดขับเพลาขนาน (เฟืองเฉียง): รูปแบบเพลาขนานเยื้องศูนย์สำหรับพื้นที่ติดตั้งแนวตรงที่จำกัด
• ติดตั้งมอเตอร์ด้านบน (Top Mount): แท่นมอเตอร์ด้านบนสำหรับระบบขับเคลื่อนด้วยสายพาน/พูลเลย์ความเร็วสูง 		ชุดขับ Hansen P4 ครบชุด, เกียร์ทดเพลาขวางเฟืองดอกจอกเฉียง, เกียร์เพลาขนานพร้อมฐานแท่นเครื่อง, ชุดขับ Hansen UniMiner
รูปแบบเกียร์ทดรอบแยกอิสระ • เกียร์ทดรอบ 1 สเตจ (Single Stage): อัตราทดต่ำประสิทธิภาพสูงสุด (1.25:1 ถึง 5:1)
• เกียร์ทดหลายสเตจ / ซ้อนชั้น: เสื้อเกียร์แบบซ้อนชั้นสำหรับแรงบิดสูงมากและอัตราทดสูง (สูงสุด 500:1)
• รุ่นเสื้อเกียร์เหล็กกล้าเชื่อมประกอบ: เสื้อเกียร์เหล็กหนาพิเศษสำหรับงานรับแรงกระแทกรุนแรงในเหมืองแร่และเรือเดินสมุทร
• เกียร์เพลาขวางและเพลาขนาน: เพลาเข้าความเร็วสูงและเพลาออกความเร็วต่ำแบบเพลาตัน 		เกียร์ 1 สเตจ Hansen P4, เกียร์หลายสเตจ Hansen P4, เกียร์อุตสาหกรรมเสื้อเหล็กงานหนัก
รูปแบบการติดตั้งอเนกประสงค์ • ติดตั้งแนวตั้งและยึดผนังแนวตั้ง: จัดวางเสื้อเกียร์ในแนวตั้งเพื่อประหยัดพื้นที่สำหรับสายพานลำเลียงแนวตั้งหรือเครื่องผสม
• ติดตั้งเพลาแนวตั้ง (เพลาชี้ลง / เพลาชี้ขึ้น): ออกแบบเฉพาะสำหรับเครื่องกวน เครื่องเติมอากาศ และหอหล่อเย็น
• ติดตั้งแขวนเพดาน (Ceiling Mount): รูปแบบแขวนกลับหัวสำหรับระบบสายพานลำเลียงเหนือศีรษะ 		เกียร์ติดตั้งแนวตั้ง Hansen P4, เกียร์เพลาแนวตั้งชี้ลงสำหรับเครื่องกวน, ชุดขับกะพ้อลำเลียง
หอหล่อเย็นและเสื้อเกียร์พิเศษ • ซีรีส์ Hansen M4 ACC: เกียร์เพลาขวางที่ออกแบบเฉพาะสำหรับคอนเดนเซอร์ระบายความร้อนด้วยอากาศ (ACC) และหอหล่อเย็นแบบเปียก
• เสื้อแบริ่งระยะกว้าง (Drop Bearing Housing): ขยายระยะห่างแบริ่งเพื่อรองรับแรงแนวรัศมีและแรงรุนแนวแกนสูงมาก (พัดลมและใบพัด)
• เพลากลวง (Shrink Disc / ร่องลิ่ม): ติดตั้งสวมเข้ากับเพลาเครื่องจักรโดยตรงโดยไม่ต้องใช้คัปปลิ้งภายนอก 		เกียร์หอหล่อเย็น Hansen M4 ACC, เกียร์ขับพัดลมระบายความร้อน, เกียร์สวมเพลาพร้อม Shrink Disc
จุดเด่นทางเทคนิคสำหรับวิศวกรและฝ่ายซ่อมบำรุง:
  • โปรไฟล์ฟันเฟืองความแข็งแรงสูง: โคนฟันหนากว่าเดิม มอบความสามารถในการรับน้ำหนักที่เหนือกว่าและทนทานต่อแรงกระแทกสูง
  • เสื้อเกียร์แบบแยกส่วนและฝาเปิดตรวจสอบ: ตรวจสอบเฟืองภายในได้ง่ายโดยไม่ต้องถ่ายน้ำมันออกหรือรื้อถอนชุดเกียร์
  • พิกัดการระบายความร้อนที่เหมาะสมที่สุด: พัดลมระบายความร้อนประสิทธิภาพสูงและฝาครอบบังคับทิศทางลมช่วยเพิ่มขีดความสามารถในการทำงานต่อเนื่อง
  • ตัวเลือกซีลกันฝุ่นไม่ต้องบำรุงรักษา: มาพร้อมซีล Taconite, ซีลน้ำมันสองชั้น (XB68/XB69) และจุกหายใจกันน้ำฉีดล้าง

ต้องการชุดเกียร์ทดแทนติดตั้งทันทีหรืออะไหล่สำหรับเกียร์ Hansen P4 / M4 ACC หรือไม่?

ขอใบเสนอราคา Hansen สำรวจผลิตภัณฑ์ Sumitomo

คำถามที่พบบ่อยเกี่ยวกับเกียร์อุตสาหกรรม Hansen

ถาม: สามารถจัดหาชุดเกียร์ทดแทนแบบติดตั้งแทนที่ได้ทันที (Drop-in Replacement) สำหรับเกียร์ Hansen P4 และ Hansen M4 ACC ที่มีอยู่เดิมได้หรือไม่?
ตอบ: ได้ครับ เราจัดจำหน่ายเกียร์อุตสาหกรรมงานหนักใหม่ 100% ของแท้ ซึ่งออกแบบให้ตรงกับฐานติดตั้ง ขนาดเพลาขาออก พิกัดความร้อน และอัตราทดของเกียร์ Hansen P4 และ M4 ACC เดิมทุกประการโดยไม่ต้องดัดแปลงฐานราก

ถาม: ความแตกต่างระหว่างเกียร์ Hansen M4 ACC และ Hansen P4 คืออะไร?
ตอบ: ซีรีส์ Hansen M4 ACC ออกแบบมาเฉพาะสำหรับคอนเดนเซอร์ระบายความร้อนด้วยอากาศ (ACC) และหอหล่อเย็นแบบเปียก โดยมีแบริ่งขาออกเสริมความแข็งแรงเพื่อรองรับแรงรุนแนวแกนสูงจากใบพัด ส่วนซีรีส์ Hansen P4 ครอบคลุมงานหนักหลายสเตจทั้งแบบแนวนอน แนวตั้ง และ UniMiner ในอุตสาหกรรมเหมืองแร่ ปูนซีเมนต์ และการลำเลียงวัสดุ

ถาม: สามารถดูข้อมูลมอเตอร์เกียร์ Sumitomo Cyclo® 6000, HYPONIC® หรือ BUDDYBOX® ได้ที่ไหน?
ตอบ: มอเตอร์เกียร์ขนาดเล็กถึงขนาดกลางและชุดขับไซคลอยด์ทั้งหมดของ Sumitomo Drive Technologies ถูกรวบรวมไว้ที่ หน้าเกียร์ทดรอบและมอเตอร์เกียร์ Sumitomo โดยเฉพาะของเรา

ถาม: อุตสาหกรรมใดบ้างที่นิยมใช้งานชุดขับอุตสาหกรรม Hansen P4 และ M4?
ตอบ: เกียร์ทดรอบงานหนักเหล่านี้ถูกใช้งานอย่างแพร่หลายในหอหล่อเย็นของโรงไฟฟ้า สายพานลำเลียงในเหมืองแร่ กะพ้อลำเลียง เตาเผาปูนซีเมนต์ เครนท่าเรือ เครื่องกวนสารเคมี และโรงงานเยื่อกระดาษ
