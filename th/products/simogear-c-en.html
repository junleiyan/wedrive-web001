มอเตอร์เกียร์หนอนเพลาเฉียง Siemens & Innomotics SIMOGEAR

แบรนด์: Siemens / Innomotics | ซีรีส์: SIMOGEAR ซีรีส์ C (ช่วงขนาด C29, C39, C49, C69, C89)
ประกาศการถือครองแบรนด์และความต่อเนื่องของสายผลิตภัณฑ์ — จาก Siemens สู่ Innomotics:
SIMOGEAR คือแพลตฟอร์มมอเตอร์เกียร์ทดเพลาตั้งฉากที่ทันสมัยและมีประสิทธิภาพสูง พัฒนาโดย Siemens เพื่อสืบทอดสายผลิตภัณฑ์แทนซีรีส์ Flender MOTOX C ดั้งเดิมโดยตรง[cite: 2] หลังจากการปรับโครงสร้างองค์กรของแผนกมอเตอร์ไฟฟ้าและมอเตอร์เกียร์ของ Siemens พอร์ตโฟลิโอ SIMOGEAR ทั้งหมดได้รับการผนวกรวมเข้าด้วยกันภายใต้แบรนด์ Innomotics[cite: 2]

ข้อได้เปรียบทางวิศวกรรม & ความเข้ากันได้ในการทดแทน MOTOX:
• ซีรีส์ SIMOGEAR C ผสานรวมประสิทธิภาพสูงของสเตจเกียร์เฟืองเฉียงขั้นต้นเข้ากับการทำงานที่เงียบเป็นพิเศษและอัตราทดสูงของสเตจเกียร์หนอน[cite: 2]
• ประกบร่วมกับ มอเตอร์ Siemens/Innomotics LE/LA (เช่น มอเตอร์ประสิทธิภาพสูง IE3 ซีรีส์ 1LE0003 และ 1LE1501) ครอบคลุมขนาดเฟรม IEC 63 ถึง IEC 160M[cite: 2]
• ทดแทนแบบตรงรุ่น (Drop-in) 100%: ขนาดของ SIMOGEAR C (C29, C39, C49, C69, C89) มีขนาดเพลากลวง/เพลาตันและมิติแขนรับแรงบิดมาตรฐานที่ออกแบบมาเพื่อทดแทนมอเตอร์เกียร์ Siemens MOTOX C รุ่นเดิม (C38, C48, C68, C88) ได้โดยตรงโดยไม่ต้องดัดแปลงโครงสร้างแท่นรองรับ[cite: 2]

ซีรีส์มอเตอร์เกียร์เพลาตั้งฉากแบบหนอนเพลาเฉียง SIMOGEAR (ซีรีส์ C) มอบโซลูชันที่คุ้มค่า ประหยัดพื้นที่ติดตั้ง และให้การทำงานที่เงียบเป็นพิเศษสำหรับงานขับเคลื่อนเพลาตั้งฉาก[cite: 2] เมื่อประกบคู่กับมอเตอร์ไฟฟ้ากระแสสลับ SIMOTICS ของ Siemens / Innomotics ขนาดตั้งแต่ 0.09 kW ถึง 15 kW มอเตอร์เกียร์ SIMOGEAR C ส่งมอบแรงบิดเอาต์พุตระบุตั้งแต่ 45 Nm ถึง 1,590 Nm[cite: 2] มีให้เลือกใช้งานทั้งแบบเพลาตัน (C/CF), เพลากลวงพร้อมร่องลิ่ม (CA/CAF), เพลากลวงพร้อมปลอกประกบเพลา (CAS/CASF) และแบบแขนรับแรงบิด นิยมใช้งานอย่างแพร่หลายในระบบสายพานลำเลียง ระบบจัดการวัสดุ เทคโนโลยีการแสดงบนเวที กระบวนการแปรรูปอาหาร และเครื่องจักรบรรจุภัณฑ์[cite: 2]

ข้อมูลจำเพาะทางเทคนิค

รุ่น / รหัสสินค้า SIMOGEAR C89-LE100LA4P (2.2 kW, 4 ขั้ว, เฟรม 100, เพลาตั้งฉากหนอนเพลาเฉียง)[cite: 2]
สายตระกูลแบรนด์ Siemens → Innomotics (จัดจำหน่ายผ่านช่องทาง OEM ของแท้ 100%)[cite: 2]
โครงสร้างการวางชุดเกียร์ ชุดทดเกียร์เพลาตั้งฉากหนอนเพลาเฉียง (โครงสร้างแบบผสม 2 ตอน / 3 ตอน)[cite: 2]
ช่วงขนาดโครงสร้าง 5 ขนาด: C29, C39, C49, C69, C89 (รวมถึงรูปแบบ CA, CAF, CF, CAS)[cite: 2]
กำลังมอเตอร์และขนาดเฟรม 0.09 kW ถึง 15 kW (ขนาดเฟรมมอเตอร์มาตรฐาน IEC 63 ถึง 160M)[cite: 2]
แรงบิดเอาต์พุตระบุ 45 Nm ถึง 1,590 Nm (ครอบคลุมทั้งซีรีส์)[cite: 2]
ช่วงอัตราทดเกียร์ (Ratio) i = 6.80 ถึง 500.00 (รองรับอัตราทดสูงในโครงสร้างเสื้อเกียร์เดี่ยว)[cite: 2]
รูปแบบเพลาและการติดตั้ง เพลาตัน, เพลากลวงพร้อมร่องลิ่ม, เพลากลวงพร้อมปลอกประกบเพลา (Shrink Disc), แขนรับแรงบิด, หน้าแปลน B5/B14[cite: 2]

ตารางการจับคู่มอเตอร์และแรงบิดสำหรับซีรีส์ SIMOGEAR C

คู่มือการจับคู่กำลัง ขนาดเฟรมมอเตอร์ และแรงบิดที่สมบูรณ์สำหรับมอเตอร์เกียร์เพลาตั้งฉากแบบหนอนเพลาเฉียง Siemens / Innomotics SIMOGEAR ตรวจสอบขนาดเฟรมมอเตอร์และขีดจำกัดแรงบิดที่รองรับ:[cite: 2]

ขนาดเฟรม SIMOGEAR แรงบิดเอาต์พุตสูงสุด (Nm) ช่วงกำลังมอเตอร์ที่รองรับ (kW) ขนาดเฟรมมอเตอร์ IEC ที่ใช้งานได้
SIMOGEAR C29 / CA29 / CAF29[cite: 2] 95 Nm[cite: 2] 0.09 kW - 1.1 kW[cite: 2] IEC 63, 71, 80[cite: 2]
SIMOGEAR C39 / CA39 / CAF39[cite: 2] 175 Nm[cite: 2] 0.12 kW - 2.2 kW[cite: 2] IEC 63, 71, 80, 90, 100[cite: 2]
SIMOGEAR C49 / CA49 / CAF49[cite: 2] 340 Nm[cite: 2] 0.25 kW - 4.0 kW[cite: 2] IEC 71, 80, 90, 100, 112[cite: 2]
SIMOGEAR C69 / CA69 / CAF69[cite: 2] 700 Nm[cite: 2] 0.55 kW - 7.5 kW[cite: 2] IEC 80, 90, 100, 112, 132[cite: 2]
SIMOGEAR C89 / CA89 / CAF89[cite: 2] 1,590 Nm[cite: 2] 1.1 kW - 15.0 kW[cite: 2] IEC 90, 100, 112, 132, 160M[cite: 2]

คู่มือการอัปเกรดโดยตรงจาก Siemens Flender MOTOX C เป็น SIMOGEAR

มอเตอร์เกียร์หนอน MOTOX รุ่นเดิมที่ยกเลิกการผลิตแล้ว (C38, C48, C68, C88) สามารถอัปเกรดเป็นรุ่นปัจจุบัน SIMOGEAR C ได้โดยตรง ตรวจสอบตารางเทียบมิติและแรงบิดแบบ 1-to-1 ด้านล่าง:[cite: 2]

รุ่นเดิม MOTOX C (เลิกผลิตแล้ว) พิกัดแรงบิดเดิม รุ่นทดแทนโดยตรงปัจจุบัน SIMOGEAR แรงบิดสูงสุด SIMOGEAR หมายเหตุความเข้ากันได้ทางกลและการติดตั้ง
MOTOX C38 / CA38 / CAF38[cite: 2] 150 Nm - 160 Nm[cite: 2] SIMOGEAR C39 / CA39 / CAF39 อัปเกรดเป็น SIMOGEAR[cite: 2] 175 Nm[cite: 2] ขนาดเพลากลวง 25mm/30mm และมิติแขนรับแรงบิดตรงกัน 100% แบบ drop-in[cite: 2]
MOTOX C48 / CA48 / CAF48[cite: 2] 280 Nm - 300 Nm[cite: 2] SIMOGEAR C49 / CA49 / CAF49 อัปเกรดเป็น SIMOGEAR[cite: 2] 340 Nm[cite: 2] ขนาดเส้นผ่านศูนย์กลางเพลากลวง 35mm และขนาดร่องลิ่มตรงกันอย่างสมบูรณ์[cite: 2]
MOTOX C68 / CA68 / CAF68[cite: 2] 600 Nm - 650 Nm[cite: 2] SIMOGEAR C69 / CA69 / CAF69 อัปเกรดเป็น SIMOGEAR[cite: 2] 700 Nm[cite: 2] คงขนาดเพลากลวง 40mm และระยะพิตช์วงกลมของหน้าแปลน B5 ดั้งเดิม[cite: 2]
MOTOX C88 / CA88 / CAF88[cite: 2] 1,300 Nm - 1,400 Nm[cite: 2] SIMOGEAR C89 / CA89 / CAF89 อัปเกรดเป็น SIMOGEAR[cite: 2] 1,590 Nm[cite: 2] ระดับประสิทธิภาพการใช้พลังงานสูงขึ้น ทดแทนตรงรุ่นสำหรับเพลากลวง 50mm[cite: 2]

บันทึกทางวิศวกรรมสำหรับการเลือกรุ่น & การดัดแปลงทดแทน

WE DRIVE HONGKONG LIMITED ให้บริการจัดหาทางเทคนิคและการกำหนดค่าทางวิศวกรรมสำหรับตระกูล มอเตอร์เกียร์หนอนเพลาเฉียง Siemens & Innomotics SIMOGEAR อย่างครบวงจร[cite: 2] ไม่ว่าโรงงานของท่านจะต้องการรุ่นติดตั้งด้วยขาตั้งแบบเพลาตัน (C29 ถึง C89), รุ่นติดตั้งสวมเพลาแบบเพลากลวงพร้อมแขนรับแรงบิด (CA29 ถึง CA89), รุ่นหน้าแปลน B5 (CF / CAF) หรือรุ่นเพลากลวงพร้อมปลอกประกบเพลา (CAS / CASF) ทุกชุดสามารถประกอบสำเร็จพร้อมเบรกหยุด, ตัวล็อกกันการหมุนกลับ, พัดลมระบายความร้อนแบบบังคับ หรือขดลวดมอเตอร์ที่รองรับการใช้งานร่วมกับอินเวอร์เตอร์ (VFD)[cite: 2]

เมื่อต้องการเปลี่ยนทดแทนมอเตอร์เกียร์รุ่นเดิม Siemens Flender ซีรีส์ MOTOX C การเลือกใช้ชุดเกียร์ SIMOGEAR C ที่ทันสมัยจะช่วยเพิ่มประสิทธิภาพการใช้พลังงานที่สูงขึ้น (มอเตอร์มาตรฐาน IE3/IE4), ลดเสียงรบกวนขณะทำงาน และยืดระยะเวลาการเปลี่ยนถ่ายน้ำมันหล่อลื่น พร้อมรับประกันการจัดแนวตำแหน่งติดตั้งทางกายภาพ 100% โดยไม่ต้องดัดแปลงแขนรับแรงบิดหรือเพลาเอาต์พุตเดิม[cite: 2] เพียงส่งภาพป้ายชื่อ (Nameplate) MOTOX C หรือ SIMOGEAR เดิมของท่านมาให้เรา ทีมวิศวกรของเราพร้อมจัดเตรียมใบเสนอราคาสำหรับรุ่นทดแทนที่เข้ากันได้อย่างสมบูรณ์[cite: 2]
