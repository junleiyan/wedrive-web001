ชุดเกียร์อุตสาหกรรม SEW X3F300e (เจเนอเรชัน Xe ขนาด 300)

แบรนด์: SEW-Eurodrive | หมวดหมู่: ชุดเกียร์อุตสาหกรรมระดับเรือธง (ช่วงขนาด X290e-X320e, ซีรีส์ M, MC, ML)

SEW X3F300e เป็นชุดเกียร์อุตสาหกรรมงานหนักพิเศษ 3 ตอนแบบเพลาขนานเฟืองเฉียง (Helical) ที่ได้รับการออกแบบภายใต้แพลตฟอร์มเรือธง เจเนอเรชัน Xe (Generation e) ของ SEW-Eurodrive[cite: 4] ให้กำลังแรงบิดเอาต์พุตระบุสูงเป็นพิเศษถึง 350.0 kNm[cite: 4] โดยซีรีส์ Xe ขนาด 290 ถึง 320 รวมเอาการปรับแต่งรูปทรงหน้าสัมผัสฟันเกียร์ การขยายพื้นที่ผิวเสื้อเกียร์เพื่อการระบายความร้อนที่ยอดเยี่ยม ชุดซีลลดแรงเสียดทาน และการยืดอายุการใช้งานของตลับลูกปืน[cite: 4] ได้รับการออกแบบให้ครอบคลุมแรงบิดระบุสูงสุดถึง 475 kNm ที่จุดสูงสุดของแพลตฟอร์ม X[cite: 4] ขนาด X290e, X300e, X310e และ X320e ให้ความเข้ากันได้ของมิติการติดตั้งแบบ 1-to-1 สมบูรณ์แบบเพื่อทดแทนชุดเกียร์เรือธงรุ่นเก่าที่ยกเลิกการผลิตแล้ว เช่น ซีรีส์ M (M2PSF90 / M3RSF90 / M3PSF100), ซีรีส์ MC (MC09) และ ซีรีส์ ML สำหรับสายพานลำเลียงหลักในเหมืองแร่ เตาเผาปูนซีเมนต์ เครนยกตู้คอนเทนเนอร์ท่าเรือ โรงบดลูกบอล และเครื่องกวนอุตสาหกรรมหนัก[cite: 4]

รุ่น / รหัสสินค้า X3F300e (เฟืองเฉียง 3 ตอน, เจเนอเรชัน Xe ขนาด 300)[cite: 4]
แบรนด์ / ผู้ผลิต SEW-Eurodrive[cite: 4]
โครงสร้างการวางชุดเกียร์ เพลาขนานเฟืองเฉียง (X.F / X.Fe) & เพลาตั้งฉากเฟืองดอกจอก-เฟืองเฉียง (X.K / X.Ke)[cite: 4]
ขนาดโครงสร้างหลักระดับเรือธง ขนาดเรือธง X290e (300 kNm), X300e (350 kNm), X310e (410 kNm), X320e (475 kNm)[cite: 4]
แรงบิดเอาต์พุตระบุ 350.0 kNm (X300e) / สูงสุด 475.0 kNm (X320e) / 6.8 ถึง 475 kNm (ครอบคลุมทั้งซีรีส์)[cite: 4]
ช่วงอัตราทดเกียร์ (Ratio) i = 6.3 ถึง 450 (โครงสร้าง 2 ตอน, 3 ตอน และ 4 ตอน)[cite: 4]
ความเข้ากันได้กับรุ่นเก่า ทดแทนแบบ Drop-in ได้โดยตรงสำหรับ SEW ซีรีส์ M (M100 / M120), MC09, M3 และ ซีรีส์ ML[cite: 4]
รูปแบบเพลา & การติดตั้ง เพลาตัน, เพลากลวงพร้อมลิ่ม/ปลอกประกบเพลา (Shrink Disc), หน้าแปลน, แขนรับแรงบิด (Torque Arm)[cite: 4]

ตารางโครงสร้างสถาปัตยกรรมโมดูลาร์ SEW ซีรีส์ X & Xe

คู่มือโครงร่างโครงสร้างสำหรับชุดเกียร์อุตสาหกรรม SEW-Eurodrive ซีรีส์ X และ Xe ทั้งในรูปแบบเฟืองเฉียงแกนขนานและเฟืองดอกจอกแกนตั้งฉาก[cite: 4] ตรวจสอบทิศทางการติดตั้ง รูปแบบการตัดเฉือนเพลา และอุปกรณ์ระบายความร้อนเสริม:[cite: 4]

โครงสร้างเกียร์ & การออกแบบซีรีส์ ช่วงขนาดโครงสร้าง พิกัดแรงบิดระบุ (kNm) อุปกรณ์เสริมมาตรฐานจากโรงงาน
X.F / X.Fe (เฟืองเฉียงแกนขนาน 2, 3, 4 ตอน)[cite: 4] X100e ถึง X320e (23 ขนาด)[cite: 4] 6.8 kNm - 475 kNm[cite: 4] /CC (ฝาครอบพัดลมระบายความร้อน)[cite: 4]
X.K / X.Ke (เฟืองดอกจอกแกนตั้งฉาก 2, 3, 4 ตอน)[cite: 4] X100e ถึง X320e (23 ขนาด)[cite: 4] 6.8 kNm - 475 kNm[cite: 4] /OW (ชุดแลกเปลี่ยนความร้อน น้ำ/น้ำมัน)[cite: 4]
X.T (เกียร์ขับกะพ้อลำเลียง 3 ตอน)[cite: 4] X100e ถึง X300e (10 ขนาด)[cite: 4] 6.8 kNm - 350 kNm[cite: 4] /OA (ชุดแลกเปลี่ยนความร้อน อากาศ/น้ำมัน)[cite: 4]
X.P (ชุดเกียร์แพลเนตทารีร่วมกับเฟืองเฉียง)[cite: 4] X100e ถึง X300e (10 ขนาด)[cite: 4] 22.0 kNm - 350 kNm[cite: 4] /BS (อุปกรณ์กันการหมุนย้อนกลับ / Backstop)[cite: 4]
ซีรีส์ MC / M / ML (รุ่นดัดแปลงทดแทนเกียร์เก่าระดับเรือธง)[cite: 4] MC02 ถึง MC09 / M50 ถึง M120 / ML[cite: 4] 6.0 kNm - 450 kNm[cite: 4] /MH (หน้าแปลนข้อต่อวิศวกรรมเฉพาะ)[cite: 4]

คู่มือการทดแทนเกียร์เก่า SEW ซีรีส์ MC / M / ML & การอัปเกรดเป็นรุ่นเรือธง Xe

ชุดเกียร์อุตสาหกรรมระดับเรือธง SEW รุ่นเดิมที่เลิกผลิตแล้ว (M2PSF90, M3RSF100, M3PSF120, MC3RL09, ซีรีส์ ML) สามารถอัปเกรดเป็นชุดเกียร์เจเนอเรชัน Xe ระดับเรือธงประสิทธิภาพสูงในปัจจุบันได้โดยตรง[cite: 4] โปรดดูตารางเทียบขนาดและแรงบิดด้านล่าง:[cite: 4]

รุ่นเกียร์เก่า (เลิกผลิตแล้ว) แรงบิดเดิม รุ่นทดแทนปัจจุบันในซีรีส์ Xe แรงบิดระบุของ Xe หมายเหตุความเข้ากันได้ทางกลและการติดตั้ง
M2PSF70 / M3RSF70 / M3PSF70[cite: 4] 120.0 kNm - 140.0 kNm[cite: 4] X2F250e / X3F250e / X3K250e อัปเกรดเป็น Xe[cite: 4] 175.0 kNm[cite: 4] แผ่นฐานรองปรับแต่งเฉพาะช่วยให้จัดแนวตรงกับสลักเกลียวฐานรากเดิมได้พอดี[cite: 4]
M2PSF80 / M3RSF80 / M3PSF80[cite: 4] 150.0 kNm - 180.0 kNm[cite: 4] X2F260e / X3F260e / X3K260e อัปเกรดเป็น Xe[cite: 4] 205.0 kNm[cite: 4] ทดแทนเกียร์งานหนักสำหรับเหมืองแร่และโรงโม่ พร้อมแผ่นฐานรอง Sub-base ทางวิศวกรรม[cite: 4]
M2PSF90 / M3RSF90 / M3PSF90[cite: 4] 200.0 kNm - 250.0 kNm[cite: 4] X2F280e / X3F280e / X3K280e อัปเกรดเป็น Xe[cite: 4] 270.0 kNm[cite: 4] ทดแทนชุดขับเคลื่อนโรงโม่หนัก M90 โดยตรง มีแผ่นฐานรอง Sub-base มาตรฐานรองรับ[cite: 4]
M2PSF100 / M3RSF100 / ซีรีส์ MC09[cite: 4] 280.0 kNm - 320.0 kNm[cite: 4] X2F300e / X3F300e / X3K300e อัปเกรดเป็น Xe[cite: 4] 350.0 kNm[cite: 4] ชุดขับเคลื่อนเรือธง 300 kNm ทดแทนชุดเกียร์รุ่นเก่า MC09 และ M100 ได้โดยตรง[cite: 4]
M2PSF120 / M3RSF120 / ซีรีส์ ML[cite: 4] 380.0 kNm - 450.0 kNm[cite: 4] X3F320e / X3K320e / X4F320e อัปเกรดเป็น Xe[cite: 4] 475.0 kNm[cite: 4] พิกัดแรงบิดสูงสุดบนแพลตฟอร์ม SEW X รองรับการเปลี่ยนผ่านแบบ Drop-in สำหรับเกียร์เรือธงซีรีส์ ML[cite: 4]

บันทึกทางวิศวกรรมสำหรับการเลือกรุ่น & การดัดแปลงทดแทน

เราเชี่ยวชาญในการจัดหาโซลูชันทางวิศวกรรมและการทดแทนที่ครอบคลุมสำหรับตระกูลชุดเกียร์อุตสาหกรรมระดับเรือธง SEW-Eurodrive X290e / X300e / X310e / X320e เจเนอเรชัน Xe ทั้งหมด[cite: 4] ไม่ว่าโรงงานขนาดใหญ่ของท่านจะต้องการชุดขับเคลื่อนเพลาขนานเฟืองเฉียง 2 ตอนหรือ 3 ตอน (X2F300e / X3F300e / X3F320e)[cite: 4], ชุดเกียร์เพลาตั้งฉากเฟืองดอกจอก-เฟืองเฉียง (X2K300e / X3K300e / X3K320e)[cite: 4], ชุดขับกะพ้อลำเลียง (X.T300e)[cite: 4] หรือชุดขับลูกผสมแพลเนตทารี (X.P300e)[cite: 4] ทุกรุ่นเรือธงสามารถกำหนดค่าได้อย่างยืดหยุ่นทั้งแบบเพลาตัน, เพลากลวงพร้อมปลอกประกบเพลา, ปั๊มน้ำมันหล่อลื่นแบบบังคับ และตัวล็อกป้องกันการหมุนกลับ[cite: 4]

หากท่านต้องการเปลี่ยนชุดเกียร์ระดับเรือธงรุ่นเก่าที่เลิกผลิตแล้ว เช่น ซีรีส์ M (ตั้งแต่ M2PSF90 ถึง M3RSF120)[cite: 4], ซีรีส์ MC09[cite: 4] หรือ ซีรีส์ ML[cite: 4] การอัปเกรดเป็นเจเนอเรชัน Xe ขนาด 290 ถึง 320 ใหม่นี้จะช่วยรับประกันความเข้ากันได้ทางกล 100% พร้อมทั้งให้อัตราทนความร้อนที่สูงขึ้นอย่างมีนัยสำคัญและยืดระยะเวลาการเปลี่ยนถ่ายน้ำมันหล่อลื่น[cite: 4] เพียงส่งหมายเลขซีเรียล (Serial Number) หรือข้อมูลบนป้ายชื่อ SEW เดิมของท่าน ทีมวิศวกรของเราพร้อมจัดเตรียมข้อกำหนดทางเทคนิคที่เข้ากันได้สมบูรณ์พร้อมใบเสนอราคาที่คุ้มค่าที่สุด[cite: 4]
