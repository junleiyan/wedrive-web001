มอเตอร์ไฟฟ้ากระแสสลับแรงดันต่ำ Siemens & Innomotics SIMOTICS 1LE0

แบรนด์: Siemens / Innomotics | ซีรีส์: SIMOTICS GP & SD (กลุ่มผลิตภัณฑ์ 1LE0, 1LE1, 1LE5)
ประกาศการเปลี่ยนแปลงแบรนด์และความเป็นเจ้าของ:
เพื่อเพิ่มประสิทธิภาพในการดำเนินงานด้านอุตสาหกรรม Siemens ได้โอนย้ายธุรกิจมอเตอร์ไฟฟ้าแรงดันต่ำไปยังองค์กรอิสระชื่อ Innomotics[cite: 2] โดยมอเตอร์ไฟฟ้าเหนี่ยวนำสามเฟสซีรีส์ SIMOTICS 1LE0, 1LE1 และ 1LE5 ที่ได้รับความนิยม ปัจจุบันได้รับการผลิตและจัดจำหน่ายภายใต้แบรนด์ Innomotics[cite: 2]

หมายเหตุเกี่ยวกับรุ่นประจำภูมิภาค: ซีรีส์ 1LE0 เป็นรุ่นมาตรฐานหลักที่ผลิตสำหรับตลาดเอเชียและจีน ในขณะที่ 1LE1 / 1LE5 เป็นรุ่นหลักสำหรับตลาดยุโรปและทั่วโลก[cite: 2] เนื่องจากสร้างขึ้นตามขนาดเฟรม IEC เดียวกัน (ขากล่อง B3, หน้าแปลน B5, หน้าแปลน B14) มอเตอร์รุ่น 1LE0 ของเอเชียจึงสามารถสลับใช้แทนรุ่น 1LE1 ของต่างประเทศได้แบบ 100% ตรงตามขนาดเดิม พร้อมมอบความคุ้มค่าสูงสุดในการอัพเกรด[cite: 2]

Siemens SIMOTICS 1LE0 Series (รวมถึง 1LE0001 IE2 และ 1LE0003 IE3 Premium Efficiency) เป็นมาตรฐานอุตสาหกรรมสำหรับมอเตอร์ไฟฟ้ากระแสสลับแบบกรงกระรอกแรงดันต่ำสามเฟส ทั้งสำหรับงานทั่วไป (GP - General Purpose) และงานหนัก (SD - Severe Duty)[cite: 2] มีให้เลือกทั้งแบบเสื้ออลูมิเนียมและเสื้อเหล็กหล่อครอบคลุมขนาดเฟรม IEC 80 ถึง 355 (0.55 kW ถึง 1,000 kW) มอเตอร์ 1LE0 ให้ประสิทธิภาพพลังงานสูง ทนทานต่อการโหลดเกินทางความร้อน (ฉนวน Class F/B) ระดับการป้องกัน IP55 และระดับเสียงต่ำ[cite: 2] นิยมนำไปใช้ในปั๊มน้ำหอยโข่ง พัดลมอุตสาหกรรม คอมเพรสเซอร์แอร์ สายพานลำเลียง เครื่องผสม และระบบขับเคลื่อนเครื่องจักรทั่วไป[cite: 2]

ประวัติสายการผลิตแบรนด์ Siemens → Innomotics (จัดจำหน่ายจากช่องทาง OEM แท้ 100%)[cite: 2]
ชื่อการจำแนกซีรีส์ SIMOTICS GP / SD (1LE0 มาตรฐานเอเชีย | 1LE1 มาตรฐานสากล | 1LE5 ประสิทธิภาพสูงพิเศษ)[cite: 2]
ระดับประสิทธิภาพพลังงาน IE2 (1LE0001), IE3 Premium (1LE0003), IE4 Super Premium (1LE0004 / 1LE15), IE5 (1LE5)[cite: 2]
ช่วงกำลังพิกัด 0.55 kW ถึง 1,000 kW (ขนาดเฟรม IEC 80 ถึง 450)[cite: 2]
จำนวนโพล (Pole) 2-Pole (3000 rpm), 4-Pole (1500 rpm), 6-Pole (1000 rpm), 8-Pole (750 rpm)[cite: 2]
ระดับการป้องกัน & ฉนวน IP55 / IP56 / IP65; ฉนวน Class F โดยมีอุณหภูมิเพิ่มขึ้นตาม Class B (155°C/80K)[cite: 2]
รูปแบบการติดตั้ง IM B3 (ขายึด), IM B5 (หน้าแปลน), IM B14 (หน้าแปลนเล็ก), IM B35 (ขายึด & หน้าแปลน)[cite: 2]

คู่มือโครงสร้างแบบโมดูลาร์สำหรับมอเตอร์ไฟฟ้ากระแสสลับสามเฟสแรงดันต่ำ Siemens / Innomotics SIMOTICS 1LE0, 1LE1, 1LE5 และ 1TL0[cite: 2] ตรวจสอบระดับประสิทธิภาพ วัสดุเฟรม และชื่อรุ่นสำหรับตลาดทั่วโลก:

SIMOTICS 1LE0003 (IE3 ประสิทธิภาพสูงพิเศษ)[cite: 2] ตลาดเอเชีย & ตลาดภูมิภาค[cite: 2] Frame 80 ถึง 355 (0.55 - 315 kW)[cite: 2] IE3 Premium เสื้อเหล็กหล่อ (งานหนัก GP/SD)[cite: 2]
SIMOTICS 1LE10 / 1LE15 (IE2 / IE3 / IE4)[cite: 2] ตลาดยุโรป & ตลาดสากล[cite: 2] Frame 80 ถึง 315 (0.55 - 250 kW)[cite: 2] อลูมิเนียม (1LE10) / เหล็กหล่อ (1LE15)[cite: 2]
SIMOTICS 1LE55 / 1LE56 (IE4 / IE5 Ultra)[cite: 2] อุตสาหกรรมหนักทั่วโลก[cite: 2] Frame 315 ถึง 450 (200 - 1000 kW)[cite: 2] เสื้อเหล็กหล่อหนาสำหรับงานหนักมาก (โหลดสูงขั้นสุด)[cite: 2]
SIMOTICS 1TL0001 / 1TL0003 (งานทั่วไป)[cite: 2] มาตรฐานอุตสาหกรรมเอเชีย[cite: 2] Frame 80 ถึง 355 (0.55 - 315 kW)[cite: 2] เสื้อเหล็กหล่อ GP มาตรฐาน (สำหรับ HVAC & พัดลม)[cite: 2]

คู่มือการทดแทนและอัพเกรดจากรุ่นต่างประเทศ 1LE1 / 1LE5 เป็นรุ่นเอเชีย 1LE0

มอเตอร์ซีรีส์ 1LE0 ของเอเชียมีขนาดการติดตั้ง IEC และความสูงศูนย์กลางเพลาเหมือนกับซีรีส์ 1LE1 และ 1LE5 ของยุโรปทุกประการ[cite: 2] มอเตอร์รุ่น 1LE1 ของต่างประเทศจึงสามารถแทนที่ด้วยรุ่น 1LE0 ที่คุ้มค่ากว่าได้โดยตรง โดยไม่ต้องดัดแปลงฐานรองหรือยอยเพลา[cite: 2]:

รุ่นต่างประเทศ / สากล (1LE1 / 1LE5) กำลังขาออกพิกัด รุ่นเอเชีย 1LE0 ที่เทียบเท่าโดยตรง ระดับประสิทธิภาพ ความเข้ากันได้ทางกล & หมายเหตุ

1LE1501-1EB2 (Frame 180M)[cite: 2] 18.5 kW / 22 kW[cite: 2] 1LE0003-1EB23-4AA4 แทนที่ได้ 100%[cite: 2] IE3 Premium[cite: 2] สลับใช้แทนกันทางกล 1:1 โดยตรง ตำแหน่งกล่องสายและระดับ IP55 เหมือนกัน[cite: 2]
1LE1501-2AB5 (Frame 200L)[cite: 2] 30 kW / 37 kW[cite: 2] 1LE0003-2AB53-4AA4 แทนที่ได้ 100%[cite: 2] IE3 Premium[cite: 2] ตรงกับเพลาขนาด 55mm คุ้มค่าสำหรับการเปลี่ยนแทนเครื่องจักรนำเข้า[cite: 2]
1LE1501-2BB0 (Frame 225M)[cite: 2] 45 kW[cite: 2] 1LE0003-2BB03-4AA4 แทนที่ได้ 100%[cite: 2] IE3 Premium[cite: 2] ความสูงศูนย์กลางเพลา IEC และขนาดการติดตั้งเหมือนกันทุกประการ ไม่ต้องดัดแปลง[cite: 2]
1LE1501-2CB2 (Frame 250M)[cite: 2] 55 kW[cite: 2] 1LE0003-2CB23-4AA4 แทนที่ได้ 100%[cite: 2] IE3 Premium[cite: 2] เสื้อเหล็กหล่อสำหรับงานหนัก เปลี่ยนใส่แทนได้ 1:1 โดยตรง[cite: 2]
1LE1501-2DB2 ถึง 3AA0 (Frame 280-315)[cite: 2] 75 kW - 200 kW[cite: 2] 1LE0003-2DB23 ถึง 3AA03 แทนที่ได้ 100%[cite: 2] IE3 Premium[cite: 2] ตรงกับขนาดฐานปั๊มและคอมเพรสเซอร์ขนาดใหญ่ ขนาดร่องลิ่มตรงกัน[cite: 2]

คำแนะนำด้านวิศวกรรมและการเลือกใช้อุปกรณ์

WE DRIVE HONGKONG LIMITED มีความเชี่ยวชาญในการจัดหาโซลูชันทางเทคนิคและการส่งมอบระดับโลกสำหรับกลุ่มผลิตภัณฑ์ Siemens & Innomotics SIMOTICS Low-Voltage AC Motor ทั้งหมด[cite: 2] ไม่ว่าโรงงานของคุณจะต้องการมอเตอร์อลูมิเนียมสำหรับงานทั่วไป (1LE10), มอเตอร์เหล็กหล่อสำหรับงานหนัก (1LE0003 / 1LE15 / 1LE55), มอเตอร์อุตสาหกรรมทั่วไป (1TL0), หรือมอเตอร์กันระเบิดสำหรับพื้นที่อันตราย (1MB0 / 1MB1) สินค้าทุกยูนิตสามารถสั่งซื้อพร้อมติดตั้งออปชันเสริม เช่น PTC Thermistor, ฮีตเตอร์ป้องกันความชื้น, ตลับลูกปืนเสริมสำหรับงานสายพาน หรือพัดลมระบายความร้อนบังคับสำหรับการทำงานร่วมกับอินเวอร์เตอร์ VFD[cite: 2]

เมื่อต้องการซ่อมบำรุงหรือเปลี่ยนมอเตอร์สำหรับเครื่องจักรนำเข้าจากยุโรปที่ใช้นามรุ่น 1LE10, 1LE15 หรือ 1LA/1LG รุ่นเก่า การเปลี่ยนมาใช้มอเตอร์ซีรีส์ 1LE0 ของเอเชียจะช่วยลดระยะเวลาการรอสินค้าและประหยัดงบประมาณได้อย่างมาก โดยยังคงรักษาระยะการติดตั้ง ความสามารถด้านความร้อน และมาตรฐานประสิทธิภาพพลังงานระดับ IE3 ไว้อย่างถูกต้อง 100%[cite: 2] เพียงส่งรหัสสินค้าบนป้ายมอเตอร์เดิมของคุณ (เช่น 1LE0003-1DB43-4AA4) หรือสเปกไฟฟ้าให้เรา ทีมงานวิศวกรของเราพร้อมจัดเตรียมข้อเสนอที่ถูกต้อง 100% ให้แก่คุณ[cite: 2]
