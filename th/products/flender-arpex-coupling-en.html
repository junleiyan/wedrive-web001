ยอยแผ่นจานยืดหยุ่น Flender ARPEX ARN-6 NEN 165-6

แบรนด์: Flender GmbH | ซีรีส์: ARPEX ยอยแผ่นจานเหล็กกล้าส่งกำลังแรงบิดสูง (ARN-6 / ARN-8 / ARN-10 / ARS-6)

Flender ARPEX ARN-6 NEN 165-6 เป็นยอยแผ่นจานยืดหยุ่นเหล็กกล้าประสิทธิภาพสูงมาตรฐานอุตสาหกรรม ออกแบบมาเพื่อการส่งกำลังที่เที่ยงตรงสูง ทรทานต่อการบิด และ**ไม่มีระยะฟรี (backlash-free 100%)** ด้วยชุดแผ่นจานสแตนเลสสปริงกำลังสูง ARPEX ARN-6 จะชดเชยการเยื้องศูนย์ของเพลาทั้งแนวตรง แนวรัศมี และแนวแกน ผ่านการยืดหยุ่นตัวของแผ่นจานโดยไม่มีชิ้นส่วนถูไถ มีจุดเด่นคือ **ไม่ต้องบำรุงรักษา** ไม่มีการสึกหรอ อายุการใช้งานไม่จำกัดหากอยู่ภายใต้ขีดจำกัดการเยื้องศูนย์ และทนต่ออุณหภูมิวิกฤต (-270°C ถึง +280°C) ยอย ARPEX มีจำหน่ายในซีรีส์หลัก ได้แก่ ซีรีส์ประสิทธิภาพสูงล่าสุด **ARN-6, ARN-8 และ ARN-10** ควบคู่ไปกับซีรีส์คลาสสิก **ARS-6, ARC-8, ARP-6, ARW-4/6 และ ART-6** โดยมีขนาดแรงบิดตั้งแต่ 92 Nm ถึง 2,000,000 Nm นิยมใช้งานในเครื่องจักรผลิตกระดาษ ปั๊มหอยโข่ง คอมเพรสเซอร์ เครื่องจักรเทอร์โบ แท่นทดสอบ กังหันลม เครื่องกำเนิดไฟฟ้า และระบบขับเคลื่อนเรือเดินสมุทร

ข้อมูลทางเทคนิค

รุ่น / รหัสสินค้า ARPEX ARN-6 NEN 165-6 (ประเภท NEN, ขนาด 165, ชุดสลัก 6 ตัว)
แบรนด์ / ผู้ผลิต Flender GmbH
รูปแบบโครงสร้างยอย ประเภท NEN (รูปแบบมาตรฐานพร้อมสเปเซอร์ระยะกลาง)
แรงบิดพิกัด (Nominal Torque) 4,800 Nm (ขนาด 165-6) / 92 Nm ถึง 2,000,000 Nm (ครอบคลุมทั้งตระกูลซีรีส์)
โครงสร้างชุดแผ่นจาน ชุดแผ่นสแตนเลสสปริงรับแรงดึงสูง ยึดด้วยสลักเกลียวรีมฟิตความแม่นยำสูง
อุณหภูมิการใช้งาน -270°C ถึง +280°C (โครงสร้างโลหะล้วน ไม่เสื่อมสภาพเหมือนยางสังเคราะห์)
มาตรฐาน ATEX ได้รับการรับรองตามมาตรฐาน Directive 2014/34/EU สำหรับพื้นที่ไวไฟ (Zone 1/21 & 2/22)
ข้อกำหนดการบำรุงรักษา ไม่ต้องบำรุงรักษา 100% & ไม่มีการสึกหรอ (ไม่ต้องอัดจาระบี)

ตารางโครงสร้างโมดูลาร์ตระกูล Flender ARPEX

คู่มือกลุ่มผลิตภัณฑ์ยอยแผ่นจานยืดหยุ่นเหล็กกล้า Flender ARPEX ฉบับสมบูรณ์ ตรวจสอบซีรีส์ที่รองรับ รูปแบบโครงสร้าง ช่วงแรงบิด และมาตรฐานการใช้งานในอุตสาหกรรมเฉพาะทาง:

ซีรีส์ยอย & การใช้งานหลัก ขนาดที่มีจำหน่าย แรงบิดพิกัด (Nm) รูปแบบโครงสร้างมาตรฐาน
ARPEX ARN-6 / ARN-8 / ARN-10 (ประสิทธิภาพแรงบิดสูง) 100-6 ถึง 610-10 (24 ขนาด) 1,200 Nm - 1,450,000 Nm NEN / NHN (สเปเซอร์มาตรฐาน & สเปเซอร์ยาว)
ARPEX ARS-6 Series (โมดูลาร์อุตสาหกรรมเอนกประสงค์) 78-6 ถึง 340-6 (10 ขนาด) 92 Nm - 32,000 Nm NEN / NHN / MNN / MHN
ARPEX Keyless Clamping Hubs (BEN / BHN / BMN) 78-6 ถึง 340-6 (10 ขนาด) 92 Nm - 32,000 Nm BEN / BHN / BMN / BMH (ดุมยึดไร้สลัก)
ARPEX ARC-8 Series (งานอุตสาหกรรมหนัก) 210-8 ถึง 850-8 (14 ขนาด) 12,000 Nm - 2,000,000 Nm NEN / NHN / BNN (ชุดขับเคลื่อนโรงงานเหล็ก/แท่นทดสอบ)
ARPEX ARP-6 Series (API 610 / API 671 ปั๊มเทอร์โบ) 105-6 ถึง 325-6 (9 ขนาด) 1,000 Nm - 30,000 Nm NAN / MCE (มาตรฐานปั๊มอุตสาหกรรม API)

คำแนะนำการดัดแปลงและอัปเกรดยอยรุ่นเก่าเป็น Flender ARPEX

ยอยแผ่นจานรุ่นเก่าหรือยอยเฟืองเกียร์ที่สึกหรอในปั๊มความเร็วสูงและเครื่องจักรเทอร์โบ สามารถดัดแปลงทดแทนด้วยยอยแผ่นจานเหล็กกล้า Flender ARPEX ได้โดยตรง อ้างอิงตารางเปรียบเทียบทดแทนแบบ 1-to-1 ด้านล่าง:

ซีรีส์ / รุ่นยอยรุ่นเดิม กลไกการทำงาน รุ่น Flender ARPEX ทดแทนปัจจุบัน ความสามารถรับแรงบิด คำแนะนำทางวิศวกรรมและการดัดแปลง
รุ่นเก่า ARS-6 Type NEN 165-6 ชุดแผ่นจานรุ่นคลาสสิก ARPEX ARN-6 Type NEN 165-6 อัปเกรดเป็น ARN 4,800 Nm ขนาดหน้าแปลนและระยะปลายเพลา DBSE ตรงกัน 1-to-1 ได้ความหนาแน่นแรงบิดสูงขึ้น
รุ่นเก่า ARS-6 Type NHN 195-6 สเปเซอร์ยาวรุ่นคลาสสิก ARPEX ARN-6 Type NHN 190-6 อัปเกรดเป็น ARN 7,500 Nm ตรงกับระยะปลายเพลา (DBSE) ของปั๊มมาตรฐาน ANSI/ISO
ยอยเฟืองเกียร์อัดจาระบี (ZAPEX) ปลอกเฟือง / ฟันเฟืองโค้ง ARPEX ARN-6 / ARC-8 Series ไม่ต้องบำรุงรักษา สูงสุด 2,000,000 Nm ขจัดปัญหาการอัดจาระบีและการสึกหรอของฟันเฟืองเกียร์ได้อย่างสิ้นเชิง
ยอยยาง / ยอยสลักรับแรงบิด ลูกยางยืดหยุ่นรับแรงบิด ARPEX ARS-6 / ARN-6 Series ส่งกำลังแบบเกร็ง 92 Nm - 32,000 Nm ส่งกำลังแรงบิดแบบไม่มีระยะฟรี และทนต่ออุณหภูมิใช้งานสูง
ปั๊มกระบวนการผลิต API 610 ชุดแผ่นจานมาตรฐาน ARPEX ARP-6 Type NAN / MCE มาตรฐาน API 1,000 Nm - 30,000 Nm มาพร้อมเพลตป้องกันการสะบัดหลุดและการถ่วงสมดุลไดนามิกจากโรงงาน

ข้อแนะนำวิศวกรรมการเลือกใช้งานและการดัดแปลง

เรามีความเชี่ยวชาญในการจัดหาเชิงเทคนิคและการแปรรูปสั่งทำพิเศษสำหรับ ตระกูลยอยแผ่นจานเหล็กกล้า Flender ARPEX ทั้งหมด ไม่ว่าระบบขับเคลื่อนของคุณจะต้องการยอยสเปเซอร์มาตรฐาน (ARN-6 / ARS-6 Type NEN), ยอยสำหรับปั๊มสเปเซอร์ยาว (Type NHN), ดุมยึดแบบไร้สลัก (Type BEN / BHN), รูปทรงกะทัดรัดประหยัดพื้นที่ (Type CEC) หรือยอยเครื่องจักรเทอร์โบมาตรฐาน API 610/671 (ARP-6 Type NAN / MCE) ดุมยอยทุกชิ้นสามารถนำมาเจาะรูเพลา ทำร่องสลัก ร่องเฟืองสเพลน์ หรือรูเพลาเตเปอร์ตามสเปกได้อย่างแม่นยำ

เมื่อต้องการดัดแปลงทดแทนยอยเฟืองเกียร์เดิมที่สึกหรอ หรือยอยรุ่นเดิม ARS-6 / ARC-8 การอัปเกรดเป็นยอยซีรีส์ ARPEX ARN ปัจจุบัน จะช่วยให้การสับเปลี่ยนขนาดทำได้ตรงกันแบบ 1-to-1 พร้อมขจัดภาระการอัดจาระบีและการบำรุงรักษาประจำปีออกไป เพียงแจ้งขนาดโตนอกเพลา ระยะปลายเพลา (DBSE) ความเร็วรอบ และกำลังมอเตอร์ ทีมวิศวกรของเราพร้อมจัดทำข้อเสนอทางเทคนิคและใบเสนอราคาที่ถูกต้อง 100%
