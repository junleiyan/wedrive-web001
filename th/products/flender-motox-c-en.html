มอเตอร์เกียร์เฟืองหนอน MOTOX C48-LA80M4

ซีรีส์: ชุดเกียร์เฟืองหนอน MOTOX | ขนาด C48 (รหัสสั่งซื้อ 2KJ1602)
ประวัติการพัฒนาแบรนด์และการเปลี่ยนความเป็นเจ้าของ:
มอเตอร์เกียร์ซีรีส์อันเป็นเอกลักษณ์ MOTOX ดั้งเดิมได้รับการออกแบบและวิศวกรรมโดย FLENDER หลังจากการควบรวมกิจการของ Siemens กับ Flender MOTOX ได้รับการรวมเข้ากับกลุ่มผลิตภัณฑ์ไดรฟ์ของ Siemens ภายใต้สายแคตตาล็อก 2KJ (2KJ1602 สำหรับ C48) ต่อมา Siemens ได้แยกธุรกิจมอเตอร์และมอเตอร์เกียร์งานหนักออกมาภายใต้แบรนด์ INNOMOTICS ปัจจุบัน ผลิตภัณฑ์ MOTOX ได้ย้ายกลับไปยังโรงงานผลิตดั้งเดิมและช่องทางซัพพลายเออร์ OEM แท้ เพื่อรับประกันความต่อเนื่องของการออกแบบ 100% สามารถสับเปลี่ยนชิ้นส่วนทางกลได้พอดี และคงมาตรฐานคุณภาพดั้งเดิม

MOTOX C48-LA80M4 เป็นมอเตอร์เกียร์เฟืองหนอนตั้งฉากแบบ 2 สเตจ ซึ่งผสานชุดเกียร์เฉียงปฐมภูมิประสิทธิภาพสูงเข้ากับชุดเกียร์หนอนขาส่งออกงานหนัก ระบุในแคตตาล็อกภายใต้รหัสสั่งซื้อ Siemens 2KJ หมายเลข 2KJ1602 ขนาด C48 ให้แรงบิดส่งออกสูงสุด 260 Nm ประกอบเข้ากับมอเตอร์ LA80M4 ขนาด 0.55 kW ออกแบบให้ทำงานเงียบ ประหยัดพื้นที่ติดตั้ง และให้ประสิทธิภาพทางกลสูงกว่าเกียร์หนอนแบบดั้งเดิมทั่วไป มอเตอร์เกียร์ MOTOX C ซีรีส์ มีโครงสร้างที่หลากหลายให้เลือก (แบบขาตั้ง C48, เพลากลวง CA48, หน้าแปลน CF48/CAF48, แคลมป์ Shrink Disc CAD48 และหน้าแปลนเสื้อเกียร์ CZ48) เหมาะอย่างยิ่งสำหรับระบบสายพานลำเลียง เครื่องจักรเวที บรรจุภัณฑ์อาหาร และระบบบำบัดน้ำเสีย

ตารางโครงสร้างโมดูลาร์ MOTOX C ซีรีส์

คู่มือการกำหนดโครงสร้างแบบโมดูลาร์ฉบับสมบูรณ์สำหรับเกียร์เฟืองหนอน Flender / Siemens / Innomotics MOTOX C ซีรีส์ ตรวจสอบขนาดเฟรม รหัสสั่งซื้อ 2KJ และรูปแบบการติดตั้งที่รองรับ:

ขนาดเกียร์ & รูปแบบการติดตั้ง รหัสนำหน้าคำสั่งซื้อ 2KJ พิกัดแรงบิดสูงสุด (Nm) ช่วงขนาดเฟรมมอเตอร์ที่จับคู่

MOTOX C48 / CA48 / CAF48 / CAD48 2KJ1602-.. 260 Nm LA71 ถึง LA100 (0.25 kW - 1.5 kW)
MOTOX C68 / CA68 / CAF68 / CAD68 2KJ1603-.. 520 Nm LA80 ถึง LA112 (0.55 kW - 3.0 kW)

ตารางเปรียบเทียบรหัสสั่งซื้อ 2KJ ของ MOTOX และแบรนด์ต่างๆ

มอเตอร์เกียร์ MOTOX ที่ติดตั้งภายใต้ป้ายชื่อ Flender, Siemens 2KJ หรือ Innomotics สามารถเทียบรหัสและจัดหาได้โดยตรงผ่านช่องทางโรงงาน OEM แท้ อ้างอิงตารางเทียบรหัสแคตตาล็อกด้านล่าง:

รหัสป้ายชื่อเดิม / ปัจจุบัน ยุคสมัยของแบรนด์ รุ่น OEM ทดแทนปัจจุบัน กำลังมอเตอร์พิกัด ความเข้ากันได้ทางกล & คำแนะนำการติดตั้ง
2KJ1600-..CB13 (C28) Siemens / Innomotics MOTOX C28-LA71B4 OEM ตรง 0.18 kW หน้าแปลนและเพลาตรงกันแบบ 1-to-1 สับเปลี่ยนได้สมบูรณ์
2KJ1601-..CD13 (C38) Siemens / Innomotics MOTOX C38-LA71S4 OEM ตรง 0.25 kW ระดับความสูงกึ่งกลางเพลาและระยะรูน็อตขาตั้งตรงกัน
2KJ1602-..DE13 (C48) Siemens / Innomotics MOTOX C48-LA80M4 OEM ตรง 0.55 kW ชุดขับ C48 มาตรฐาน เปลี่ยนใส่แทนได้พอดี 100%
2KJ1603-..EM13 (C68) Siemens / Innomotics MOTOX C68-LA90SB4E OEM ตรง 0.75 kW ชุดขับสายพานลำเลียงหนัก ใช้แขนยึดแรงบิด/หน้าแปลนเดิมได้
2KJ1604-..FM13 (C88) Siemens / Innomotics MOTOX C88-LA100ZLP4E OEM ตรง 1.5 kW ความจุแรงบิดสูงสุดสำหรับ C ซีรีส์ เปลี่ยนทดแทนได้ตรงรุ่น 100%

ข้อแนะนำวิศวกรรมการเลือกใช้งานและการดัดแปลง

เรามีความเชี่ยวชาญในการจัดหาชุดเกียร์ครบชุดและการเปลี่ยนทดแทนเชิงเทคนิคสำหรับ Flender / Siemens / Innomotics MOTOX C ซีรีส์ ทั้งหมด ไม่ว่าคุณจะต้องการรุ่นขาตั้งเพลาตัน (C28 ถึง C88), รุ่นเพลากลวง (CA28 ถึง CA88), รุ่นติดตั้งหน้าแปลน B5/B14 (CF / CAF), รุ่นเชื่อมต่อแคลมป์ Shrink Disc (CAD / CADF) หรือรุ่นหน้าแปลนเสื้อเกียร์แบบ CZ (CZ) โครงสร้างทางกลทั้งหมดสามารถจัดหาแบบประกอบสำเร็จพร้อมมอเตอร์ MOTOX ซีรีส์แท้

เมื่อต้องการเปลี่ยนทดแทนมอเตอร์เกียร์เดิม เช่น Flender MOTOX หรือ Siemens 2KJ1602 การสั่งซื้อตรงผ่านช่องทาง OEM แท้ จะช่วยให้มั่นใจได้ถึงความเข้ากันได้ของขนาด 100% รูปทรงฟันเกียร์ตามสเปกดั้งเดิม และไม่มีค่าใช้จ่ายในการดัดแปลง เพียงส่งรหัสสั่งซื้อ Siemens 2KJ หรือหมายเลขซีเรียลป้ายชื่อมาให้เรา ทีมวิศวกรของเราพร้อมจัดทำข้อเสนอที่ถูกต้อง 100%
