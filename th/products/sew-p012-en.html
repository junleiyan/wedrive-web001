ชุดเกียร์พลาเนตตารี SEW P012 Series & มอเตอร์เกียร์ผสม

แบรนด์: SEW-Eurodrive | ซีรีส์: P Series Industrial Planetary Gear Units (Size 012)

SEW P012 Series คือชุดเกียร์พลาเนตตารีอุตสาหกรรมขนาดกลาง-ใหญ่สำหรับงานหนัก ออกแบบมาเพื่อให้แรงบิดขาออกมหาศาล (แรงบิดพิกัดประมาณ 36 kNm) พร้อมความจุความร้อนดีเยี่ยมและความแข็งแรงทางกลสูง[cite: 2] ด้วยการประกอบสเตจพลาเนตตารี P012 เข้ากับชุดเกียร์หลักมาตรฐานของ SEW เช่น K-Series (Helical-Bevel), R-Series (Helical), F-Series (Parallel Shaft) และ S-Series (Helical-Worm) ทำให้ระบบขับเคลื่อนโมดูลาร์นี้บรรลุอัตราทดเกียร์สูงมาก ทิศทางเพลาที่ยืดหยุ่น และประสิทธิภาพยอดเยี่ยมสำหรับเครื่องป้อนผ้ากันเอเปรอนหนัก รถตักตักล้อสคูป เครื่องผสมอุตสาหกรรม เครื่องย่อย กว้าน และชุดขับเคลื่อนประมวลผลวัสดุปริมาณมาก[cite: 2]

ข้อมูลทางเทคนิค (Technical Specifications)

รุ่นสินค้า / ซีรีส์ P012 / PK012 / PR012 / PF012 / PS012 (ชุดเกียร์พลาเนตตารีผสม)[cite: 2]
แบรนด์ / ผู้ผลิต SEW-Eurodrive[cite: 2]
ประเภทชุดเกียร์ ชุดเกียร์พลาเนตตารีอุตสาหกรรม (ขนาด 012, แรงบิดพิกัดประมาณ 36 kNm)[cite: 2]
ชุดเกียร์หลักที่รองรับ K77 / K87 / K97 (Bevel), R77 / R87 / R97 (Helical), F77 / F87 / F97 (Parallel), S77 / S87 / S97 (Worm)[cite: 2]
กำลังมอเตอร์ IE3 DRN ที่รองรับ 5.5 kW ถึง 30.0 kW (ขนาดเฟรมมาตรฐานคู่กับเกียร์หลัก)
ความเร็วขาออก / ช่วงอัตราทด อัตราทดสูงพิเศษ สามารถปรับแต่งได้สูงถึง i = 4000+
การติดตั้ง & เพลาขาออก เพลาตันพร้อมลิ่ม/สพไลน์, เพลากลวงพร้อม Shrink Disc, การติดตั้งแบบหน้าแปลน / ขาตั้ง[cite: 2]

ตารางการผสมรุ่นและการติดตั้ง SEW P012 Series

คู่มือการเลือกรุ่นโมดูลาร์แบบครอบคลุมสำหรับชุดเกียร์พลาเนตตารี SEW Size 012[cite: 2] ตรวจสอบตัวเลือกเพลาขาออก การจับคู่กับเกียร์ทดรอบหลัก (ซีรีส์ K, R, F, S)[cite: 2] และการทำงานร่วมกับมอเตอร์ IE3 DRN รุ่นปัจจุบัน:

รูปแบบเกียร์พลาเนตตารีผสม ซีรีส์เกียร์ทดรอบหลัก ช่วงขนาดเฟรมมอเตอร์ที่รองรับ รูปแบบเพลาขาออกทางกล
PK012 / P012 KF (Bevel เข้ามุมฉาก) เกียร์ทดรอบ Bevel K77 / K87 / K97[cite: 2] DRN Series (112M4 ถึง 200L4 / 5.5 kW - 30 kW) เพลาตันพร้อมลิ่ม (PIN / PKS)
PR012 / P012 RF (Helical แกนร่วม) เกียร์ทดรอบ Helical R77 / R87 / R97[cite: 2] DRE Series (IE2 ประสิทธิภาพสูง) เพลาตันร่องสพไลน์ (DIN 5480)
PF012 / P012 FF (Parallel Shaft เพลาขนาน) เกียร์ทดรอบ เพลาขนาน F77 / F87 / F97[cite: 2] DRS Series (IE1 ประสิทธิภาพมาตรฐาน) เพลากลวงพร้อม Shrink Disc (PHH / PSH)
PS012 / P012 SF (Helical-Worm) เกียร์ทดรอบ Worm S77 / S87 / S97[cite: 2] DV / DT Series (มอเตอร์รุ่นเก่าสำหรับเปลี่ยนทดแทน) เพลากลวงร่องสพไลน์ (DIN 5480)

คู่มือการปรับปรุงเกียร์หลัก/มอเตอร์รุ่นเก่า และการอัปเกรดเป็น IE3 DRN

มอเตอร์ซีรีส์รุ่นเก่าที่ยกเลิกการผลิตแล้ว (DT, DV) ที่ติดตั้งบนชุดเกียร์พลาเนตตารีผสม P012 สามารถทดแทนได้โดยตรงด้วยมอเตอร์ประสิทธิภาพสูง IE3 Premium Efficiency DRN[cite: 2] โปรดดูตารางเปรียบเทียบการเปลี่ยนทดแทนแบบ 1-to-1 ด้านล่าง:

รหัสชุดขับเคลื่อนหลักรุ่นเก่า (เลิกผลิต) ระดับประสิทธิภาพ ชุดขับเคลื่อนทดแทน IE3 รุ่นปัจจุบัน กำลังพิกัด (kW) ข้อสังเกตความเข้ากันได้ทางกลและการดัดแปลง
PK012-K77-DV132M4[cite: 2] IE1 / ประสิทธิภาพมาตรฐาน PK012-K77-DRN132M4 อัปเกรด IE3[cite: 2] 7.5 kW - 9.2 kW หน้าแปลนตรงกันแบบ 1-to-1 เข้ากับตัวเรือน P012 โดยตรง ประหยัดพลังงานมากกว่า
PK012-K87-DV160M4[cite: 2] IE1 / IE2 ประสิทธิภาพ PK012-K87-DRN160M4 อัปเกรด IE3[cite: 2] 11.0 kW - 15.0 kW จุดเชื่อมต่อทางกลเหมือนกันทุกประการกับหน้าแปลนขาเข้าพลาเนตตารี P012
PK012-K87-DV180M4 / L4[cite: 2] IE1 / IE2 ประสิทธิภาพ PK012-K87-DRN180L4 อัปเกรด IE3 18.5 kW - 22.0 kW ชุดขับเคลื่อนพลาเนตตารีเข้ามุมฉากมาตรฐาน ตรวจสอบการตั้งค่าพารามิเตอร์ VFD
PR012-R87-DV160M4 / L4[cite: 2] IE1 / IE2 ประสิทธิภาพ PR012-R87-DRN160M4 อัปเกรด IE3[cite: 2] 11.0 kW - 15.0 kW รักษาระดับแกนร่วมเดิม ถอดเปลี่ยนใส่แทน PR012 ได้ทันที
PF012-F87-DV160M4[cite: 2] IE1 / IE2 ประสิทธิภาพ PF012-F87-DRN160M4 อัปเกรด IE3[cite: 2] 11.0 kW - 15.0 kW เข้ากันได้โดยสมบูรณ์กับสเตจเกียร์ทดรอบหลัก SEW F-series
PK012-K97-DV200L4[cite: 2] IE1 / IE2 ประสิทธิภาพ PK012-K97-DRN200L4 อัปเกรด IE3[cite: 2] 30.0 kW การจับคู่ความจุกำลังสูงสุดสำหรับสเตจขับเคลื่อนหลัก P012

คำแนะนำด้านวิศวกรรมและการเลือกใช้อุปกรณ์

เรามีความเชี่ยวชาญในการจัดหาตามสเปกวิศวกรรมและโซลูชันทางเทคนิคในการเปลี่ยนทดแทนสำหรับกลุ่มผลิตภัณฑ์ เกียร์พลาเนตตารี SEW-Eurodrive P012 Series ทั้งหมด[cite: 2] ไม่ว่าคุณจะต้องการชุดผสมพลาเนตตารี Bevel เข้ามุมฉาก (PK012 / P012 KF)[cite: 2], ชุดพลาเนตตารี Helical แกนร่วม (PR012 / P012 RF)[cite: 2], ชุดเพลาขนาน (PF012 / P012 FF)[cite: 2] หรือชุดผสม Worm (PS012 / P012 SF)[cite: 2] ทุกรูปแบบสามารถจัดส่งแบบประกอบสำเร็จพร้อม มอเตอร์ DRN มาตรฐาน IE3 รุ่นใหม่ (DRN112M4 ถึง DRN200L4)

เมื่อต้องการเปลี่ยนทดแทนระบบงานหนักเดิมที่ใช้นำมอเตอร์ขับเคลื่อนหลักรุ่นเก่า (DV132, DV160, DV180 หรือ DV200)[cite: 2] การอัปเกรดเป็นมอเตอร์ IE3 DRN จะช่วยรับประกันความเข้ากันได้ทางมิติแบบ 100% ในขณะเดียวกันก็ช่วยลดความร้อนสะสมขณะใช้งานและลดต้นทุนค่าไฟฟ้าได้อย่างมีนัยสำคัญ เพียงส่งหมายเลขซีเรียล SEW เดิมหรือข้อมูลป้ายชื่อ (รวมถึงออปชันเสริม เช่น เบรก BE, เทอร์มิสเตอร์ TF หรือสลัก Backstop) มาให้เรา ทีมงานวิศวกรของเราพร้อมจัดทำสเปกทดแทนที่ถูกต้อง 100% พร้อมข้อเสนอราคา
