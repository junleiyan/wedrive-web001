เกียร์มอเตอร์เพลาร่วมเฮลิคอลเพลาขนาน SEW FA57DRN100L4

แบรนด์: SEW-Eurodrive | ซีรีส์: FA-Series (เพลาขนาน เพลากลวง)

SEW FA57DRN100L4 เป็นเกียร์มอเตอร์เพลาร่วมเฮลิคอลเพลาขนานสำหรับงานอุตสาหกรรมที่แข็งแกร่งและกะทัดรัด มาพร้อมดีไซน์แบบเพลากลวง[cite: 2] ออกแบบมาเพื่อให้มีประสิทธิภาพทางกลสูง ระบายความร้อนได้ดีเยี่ยม และรองรับพื้นที่ติดตั้งที่จำกัด นิยมใช้อย่างแพร่หลายในระบบลำเลียง เครื่องกวนอุตสาหกรรม เครื่องจักรบรรจุภัณฑ์ และระบบระบบอัตโนมัติในโรงงาน[cite: 2]

ตารางการกำหนดโครงสร้างแบบโมดูลาร์ SEW F57 Series

คู่มือการประกอบโครงสร้างโมดูลาร์แบบครบวงจรสำหรับชุดเกียร์เพลาขนาน SEW-Eurodrive ขนาด 57[cite: 2] ตรวจสอบรูปแบบการติดตั้งทางกล มอเตอร์จับคู่มาตรฐาน IE1-IE4 และอุปกรณ์เสริมการปกป้องจากโรงงาน:

FAZ57 (หน้าแปลน B14)[cite: 2] Size 57[cite: 2] DV / DT Series (มอเตอร์รุ่นเก่า: DT71 ถึง DV112)[cite: 2] /RS (ระบบล็อกหมุนทางเดียว Backstop)

คู่มือการเปลี่ยนมอเตอร์ SEW รุ่นเก่า & อัปเกรดเป็น IE3 DRN

มอเตอร์ SEW รุ่นเก่าที่เลิกผลิตแล้ว (DT, DV, DRS, DRE) ที่ติดตั้งบนชุดเกียร์ F57 สามารถเปลี่ยนทดแทนด้วยมอเตอร์ประสิทธิภาพสูง IE3 DRN ได้อย่างไร้รอยต่อ อ้างอิงตารางเปรียบเทียบการเปลี่ยนทดแทนแบบ 1 ต่อ 1 ด้านล่าง:

รหัสมอเตอร์รุ่นเก่า (เลิกผลิต) ระดับประสิทธิภาพ มอเตอร์ทดแทน IE3 รุ่นปัจจุบัน กำลังพิกัด (kW) ความเข้ากันได้ทางกล & หมายเหตุ
DT71D4 / DV71D4 IE1 / ประสิทธิภาพมาตรฐาน DRN71M4 อัปเกรด IE3 0.37 kW - 0.55 kW ขนาดหน้าแปลนและเพลาตรงกัน 100% บนเกียร์ F57 ลดการสูญเสียพลังงาน
DT80N4 / DV80N4 IE1 / ประสิทธิภาพมาตรฐาน DRN80M4 อัปเกรด IE3 0.75 kW ขนาดการติดตั้งเหมือนกันทุกประการ สามารถถอดเปลี่ยนแทนได้ทันที
DT90S4 / DV90S4 IE1 / ประสิทธิภาพมาตรฐาน DRN90S4 อัปเกรด IE3 1.1 kW ขนาดหน้าแปลนและเพลาเท่ากัน ควรตรวจสอบตำแหน่งของกล่องสายไฟ
DT90L4 / DV90L4[cite: 2] IE1 / ประสิทธิภาพมาตรฐาน[cite: 2] DRN90L4 อัปเกรด IE3[cite: 2] 1.5 kW - 2.2 kW รองรับอแดปเตอร์ B5/B14 ได้สมบูรณ์ สอดคล้องตามมาตรฐาน IE3 ยุคใหม่
DV100M4 / DRE100M4 IE1 / IE2 ประสิทธิภาพสูง DRN100LS4 อัปเกรด IE3 2.2 kW - 3.0 kW เปลี่ยนทดแทนโดยตรงบนชุดเกียร์ F57, FA57, FAF57 และ FH57
DV100L4 / DRE100L4[cite: 2] IE1 / IE2 ประสิทธิภาพสูง[cite: 2] DRN100L4 อัปเกรด IE3[cite: 2] 3.0 kW - 4.0 kW[cite: 2] ชุดจับคู่มอเตอร์มาตรฐานสำหรับ FA57 ทดแทนรุ่นเก่า DV100L4 ได้ทันที[cite: 2]
DV112M4 / DRE112M4[cite: 2] IE1 / IE2 ประสิทธิภาพสูง[cite: 2] DRN112M4 อัปเกรด IE3[cite: 2] 4.0 kW - 5.5 kW ระยะความสูงศูนย์กลางเพลาและรูยึดตรงกัน รองรับตัวเลือกเบรก BE2/BE5
DV132S4 / DRE132S4 IE1 / IE2 ประสิทธิภาพสูง DRN132S4 อัปเกรด IE3 5.5 kW - 7.5 kW[cite: 2] จับคู่กำลังสูงสุดสำหรับซีรีส์ F57 เหมาะสำหรับงานโหลดหนัก

คำแนะนำด้านวิศวกรรมสำหรับการเลือกและอัปเกรด

เรามีความเชี่ยวชาญในการจัดหาโซลูชันระบบขับเคลื่อนแบบครบวงจรและบริการทางเทคนิคสำหรับการเปลี่ยนทดแทนชุดเกียร์ SEW-Eurodrive F57 Series[cite: 2] ทั้งหมด ไม่ว่าคุณจะต้องการแบบเพลาตันติดตั้งแบบขาตั้ง (F57)[cite: 2], แบบเพลากลวงพร้อมร่องคีย์ (FA57)[cite: 2], หน้าแปลนขาออก B5 (FAF57 / FF57)[cite: 2], ระบบล็อกแผ่นบีบ Shrink Disc (FH57)[cite: 2] หรือระบบจับล็อกแบบไม่มีร่องคีย์ TorqLOC® (FT57)[cite: 2] โครงสร้างทางกลทั้งหมดสามารถประกอบพร้อมมอเตอร์รุ่นใหม่มาตรฐาน IE3 ซีรีส์ DRN (DRN71M4 ถึง DRN112M4)[cite: 2]

เมื่อต้องการอัปเกรดระบบเดิมที่ใช้นานแล้วซึ่งติดตั้งมอเตอร์รุ่นเก่าอย่าง DT71, DT80, DT90, DV100 หรือ DV112[cite: 2] การเปลี่ยนมาใช้มอเตอร์ IE3 DRN จะช่วยรับประกันความเข้ากันได้ของขนาด 100% พร้อมทั้งช่วยลดความร้อนขณะทำงานและประหยัดค่าไฟฟ้าได้อย่างมีนัยสำคัญ เพียงส่ง Serial Number หรือภาพเนมเพลตSEW เดิมของคุณมาให้เรา (รวมถึงตัวเลือกอย่าง เบรก BE, เซ็นเซอร์ความร้อน TF หรือระบบ Backstop RS) ทีมวิศวกรของเรายินดีจัดหาสเปกทดแทนที่ถูกต้องและใบเสนอราคาให้อย่างรวดเร็ว
