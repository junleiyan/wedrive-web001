เกียร์อุตสาหกรรมเฟืองเฉียง Flender ONE H2SHN0096

แบรนด์: Flender GmbH | ซีรีส์: Flender ONE (เฟืองเฉียงสเตจเดียว H1SHN / NH1 & หลายสเตจ H..N / B..N)

Flender ONE H2SHN0096 คือชุดเกียร์อุตสาหกรรมเฟืองเฉียง 2 สเตจแบบเพลาขนานที่เป็นรุ่นอ้างอิงมาตรฐานจากแพลตฟอร์มยุคใหม่ Flender ONE ของ Flender ออกแบบมาเพื่อทดแทนชุดเกียร์ FZG Size 7 รุ่นดั้งเดิม ด้วยการใช้เทคโนโลยีเฟืองรุ่นใหม่ Metaperform® และหลักการออกแบบขนาดที่สมบูรณ์แบบ (Perfect Sizing) ทำให้ Flender ONE สามารถลดการสูญเสียพลังงานจากการเสียดทานได้สูงสุด 50% เพิ่มพื้นที่การระบายความร้อนที่ผิวสัมผัสขึ้น 35% ยืดอายุการใช้งานของตลับลูกปืนได้มากกว่า 80% (มากกว่า 100,000 ชั่วโมง) และลดปริมาณการใช้น้ำมันหล่อลื่นลงสูงสุด 20% ทุกยูนิตมาพร้อมเซนเซอร์อัจฉริยะ AIQ® Core ที่ติดตั้งมาจากโรงงานสำหรับการวิเคราะห์สภาพเกียร์แบบดิจิทัลเรียลไทม์และการบำรุงรักษาเชิงคาดการณ์ Flender ONE ยังคงใช้ขนาดระยะการติดตั้งและระยะจุดศูนย์กลางเพลาเดียวกันกับรุ่นก่อนหน้า จึงมั่นใจได้ว่าสามารถสลับเปลี่ยนแทนที่แบบ 1:1 ได้ทันที พร้อมความหนาแน่นของกำลังที่สูงขึ้นและลดค่าใช้จ่ายในการดำเนินงาน (OPEX) ลงอย่างมาก

ข้อมูลทางเทคนิค

รุ่น / รหัสสินค้า H2SHN0096 (เพลาขนาน 2 สเตจ ขนาดเฟรม 0096 Flender ONE)
แบรนด์ / ผู้ผลิต Flender GmbH
รูปแบบการออกแบบชุดเกียร์ เฟืองเฉียงสเตจเดียว (H1SHN), 2 สเตจ (H2SHN), 3 สเตจ (H3SHN), ดอกจอก 2 สเตจ (B2SHN), ดอกจอก 3 สเตจ (B3SHN)
รหัสรุ่นเก่าสำหรับสับเปลี่ยน สามารถสลับเปลี่ยนแทนที่รุ่น Flender FZG H2SH07 / H2DH07 ได้แบบ 1:1 ทันที
แรงบิดปกติส่งออก (Nominal Torque) 24.0 kNm (ขนาด 0096) / 6.7 kNm ถึง 153 kNm (ตารางรุ่นมาตรฐาน)
เทคโนโลยีชุดเฟือง หน้าฟันเฟืองปรับแต่งพิเศษ Metaperform® พร้อมอัตราทดที่แม่นยำตรงตามการใช้งาน
ระบบวิเคราะห์อัจฉริยะ ติดตั้งเซนเซอร์ AIQ® Core (วัดความสั่นสะเทือน อุณหภูมิ คุณภาพน้ำมัน และแรงบิด)
การเพิ่มประสิทธิภาพความร้อน ลดการสูญเสียกำลังลงสูงสุด 50% และเพิ่มความสามารถในการรับภาระความร้อนขึ้น +30%

ตารางโครงสร้างโมดูลาร์แพลตฟอร์ม Flender ONE

คู่มือการกำหนดโครงสร้างแบบโมดูลาร์ฉบับสมบูรณ์สำหรับเกียร์อุตสาหกรรมสเตจเดียวและหลายสเตจ Flender ONE ตรวจสอบรูปแบบสเตจ รหัสขนาดรุ่นใหม่ และอุปกรณ์เสริมการเฝ้าระวังอัจฉริยะ:

สเตจชุดเกียร์ & รหัสเรียกโครงสร้าง ช่วงรหัสขนาดรุ่นใหม่ พิกัดแรงบิดปกติ (kNm) อุปกรณ์เสริมมาตรฐานจากโรงงาน & คุณสมบัติอัจฉริยะ
H1SHN / NH1 (เฟืองเฉียงความเร็วสูง สเตจเดียว) 0026 ถึง 0541 (11 ขนาด) 6.7 kNm - 153.0 kNm AIQ® Core (เซนเซอร์วัดความสั่นสะเทือน/อุณหภูมิในตัว)
H2SHN / H3SHN / H4SHN (เฟืองเฉียงเพลาขนาน หลายสเตจ) 0024 ถึง 0541 (16 ขนาด) 6.7 kNm - 153.0 kNm Metaperform® (ลดแรงเสียดทานสูญเสียลง 50%)
B2SHN / B3SHN / B4SHN (เฟืองดอกจอกตั้งฉาก หลายสเตจ) 0042 ถึง 0541 (15 ขนาด) 6.7 kNm - 153.0 kNm Perfect Sizing (อัตราทดสั่งทำพิเศษ)
เพลากลวงแบบ Shrink Disc (ซีรีส์ DHN) 0063 ถึง 0312 (10 ขนาด) 12.0 kNm - 110.0 kNm 100,000h+ (ยืดอายุการใช้งานตลับลูกปืน)
เพลากลวงแบบมีร่องคีย์ (ซีรีส์ HHN) 0096 ถึง 0234 (4 ขนาด) 24.0 kNm - 75.0 kNm -20% Oil (ลดปริมาณการเติมน้ำมันหล่อลื่น)

คู่มือการเปลี่ยนทดแทนเกียร์ Flender FZG รุ่นเดิมเป็น Flender ONE

เกียร์ Flender FZG รุ่นดั้งเดิมที่เลิกผลิตแล้วซึ่งติดตั้งอยู่ในสายการผลิตอุตสาหกรรม สามารถเปลี่ยนทดแทนเป็นเกียร์ยุคใหม่ Flender ONE ได้โดยตรง อ้างอิงตารางเปรียบเทียบขนาดการเปลี่ยนทดแทนแบบ 1:1 ด้านล่าง:

รหัสขนาด FZG เดิม (เลิกผลิต) รุ่น FZG เดิม รุ่นเทียบเท่า Flender ONE ปัจจุบัน พิกัดแรงบิด Flender ONE การเปลี่ยนทดแทน 1:1 & ประสิทธิภาพการทำงานที่ดีขึ้น
FZG Size 3 / Size 4 H1SH03 / H2SH04 H1SHN0026 / H2SHN0042 Flender ONE 6.7 - 12.0 kNm ขนาดฐานและเพลาตรงกันแบบ 1:1 ลดแรงเสียดทานสูญเสียลง 50%
FZG Size 5 / Size 6 H2SH05 / H2SH06 H2SHN0063 / H2SHN0070 Flender ONE 15.0 - 18.0 kNm ระยะแนวศูนย์กลางเพลาเท่ากัน เพิ่มพื้นที่ระบายความร้อน 35%
FZG Size 7 / Size 8 H2SH07 / H2SH08 H2SHN0096 / H2SHN0104 Flender ONE 24.0 - 30.0 kNm สลับใส่แทน Size 7 ได้ทันที ติดตั้งเซนเซอร์ AIQ® Core จากโรงงาน
FZG Size 9 / Size 10 H2SH09 / H2SH10 H2SHN0136 / H2SHN0151 Flender ONE 42.0 - 48.0 kNm ใช้ตำแหน่งรูยึดน็อตเดิม ยืดอายุตลับลูกปืนได้มากกว่า 100,000 ชั่วโมง
FZG Size 11 ถึง Size 19 H2SH11 ถึง H2SH19 H2SHN0179 ถึง H2SHN0541 Flender ONE 60.0 - 153.0 kNm เปลี่ยนทดแทนเกียร์สายพานลำเลียงและโรงบดขนาดใหญ่ ลดปริมาณน้ำมัน

ข้อแนะนำวิศวกรรมการเลือกใช้งานและการสับเปลี่ยนทดแทน

เรามีความเชี่ยวชาญในการจัดหาและให้บริการโซลูชันวิศวกรรมการเปลี่ยนทดแทนสำหรับ แพลตฟอร์มเกียร์อุตสาหกรรมยุคใหม่ Flender ONE ทั้งหมด ไม่ว่าโรงงานของคุณจะต้องการเกียร์เฟืองเฉียงความเร็วสูงสเตจเดียว (H1SHN / NH1), เกียร์ลดความเร็วเพลาขนานหลายสเตจ (H2SHN / H3SHN / H4SHN), เกียร์ดอกจอกตั้งฉากหลายสเตจ (B2SHN / B3SHN / B4SHN), เกียร์เพลากลวงแบบ Shrink Disc (ซีรีส์ DHN) หรือเพลากลวงแบบมีร่องคีย์ (ซีรีส์ HHN) ทุกยูนิตมาพร้อมเทคโนโลยีเฟือง Metaperform® และระบบวิเคราะห์อัจฉริยะ AIQ® Core ที่ติดตั้งมาจากโรงงาน

เมื่อต้องการเปลี่ยนทดแทนเกียร์รุ่นเดิมอย่าง Flender FZG H2SH07, H2SH09, H2SH11 หรือเกียร์อุตสาหกรรมแบรนด์อื่น การอัปเกรดเป็น Flender ONE จะช่วยให้สามารถสับเปลี่ยนทางกลไกได้แบบ 1:1 โดยไม่ต้องแก้ไขฐานแท่นวางหรือเพลาขับเดิม พร้อมทั้งช่วยลดเสียงรบกวน ลดความร้อนสะสม และลดค่าไฟฟ้าอย่างเห็นได้ชัด เพียงส่งหมายเลขซีเรียลหรือข้อมูลบนป้ายชื่อเกียร์ Flender เดิมของคุณให้เรา ทีมวิศวกรของเราพร้อมเสนอสเปกที่ถูกต้อง 100%
