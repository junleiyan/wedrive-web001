อินเวอร์เตอร์เอนกประสงค์ ABB ACS580

แบรนด์: ABB | หมวดหมู่: อินเวอร์เตอร์เอนกประสงค์ที่รองรับการใช้งานอย่างครอบคลุม (ช่วงกำลังไฟฟ้า 0.75 kW ถึง 500.0 kW)

ซีรีส์อินเวอร์เตอร์ ABB ACS580 (รุ่นตัวอย่าง: ACS580-01-045A-4 22 kW 400V)[cite: 2] เป็นแพลตฟอร์มไดรฟ์ปรับความเร็วรอบเอนกประสงค์หลักของ ABB ที่ออกแบบมาเพื่อลดความยุ่งยากในการควบคุมกระบวนการผลิต[cite: 2] ลดการใช้พลังงาน[cite: 2] และเพิ่มประสิทธิภาพการทำงานของการควบคุมมอเตอร์ในแอปพลิเคชันอุตสาหกรรมที่หลากหลาย[cite: 2] มาพร้อมอุปกรณ์มาตรฐานอย่าง **ชอล์กแปรผันในตัวสำหรับลดฮาร์มอนิก**[cite: 2] ฟิลเตอร์ Class C2 EMC[cite: 2] และระบบความปลอดภัย **Safe Torque Off (STO SIL3/PL e)**[cite: 2] ทำให้ใช้งานได้แบบ Plug-and-Play โดยไม่ต้องติดตั้งอุปกรณ์เพิ่มเติมในตู้คอนโทรล[cite: 2] ครอบคลุมกำลังไฟฟ้าตั้งแต่ 0.75 kW ถึง 500.0 kW บนระบบไฟ 3 เฟส 208V ถึง 480V (ขนาดเฟรม R1 ถึง R11)[cite: 2] รองรับการควบคุมแบบ Vector สำหรับมอเตอร์เหนี่ยวนำ[cite: 2] มอเตอร์แม่เหล็กถาวร[cite: 2] และมอเตอร์ Synchronous Reluctance (SynRM) มาตรฐาน IE5[cite: 2] ออกแบบมาพร้อมแผงควบคุมอัจฉริยะที่รองรับ Modbus RTU ในตัว และการเชื่อมต่อบลูทูธเสริม[cite: 2] ไดรฟ์ ACS580 ทำหน้าที่เป็นรุ่นทดแทนโดยตรงสำหรับไดรฟ์รุ่นเก่าอย่าง **ABB ACS550** และ **ACS510**[cite: 2] ในงานปั๊ม พัดลม สายพานลำเลียง คอมเพรสเซอร์ และเครื่องกวน[cite: 2]

ข้อมูลทางเทคนิค

รุ่นตัวอย่าง ACS580-01-045A-4 (22 kW, 45A, แรงดันไฟขาเข้า 3 เฟส 380V-480V, ติดตั้งติดผนัง เฟรม R4)[cite: 2]
แบรนด์ / ผู้ผลิต ABB (แผนก Motion Drive)[cite: 2]
ซีรีส์ผลิตภัณฑ์ ไดรฟ์เอนกประสงค์ ACS580: ACS580-01 (แบบติดผนัง), ACS580-04 (โมดูล), ACS580-07 (แบบตู้สำเร็จ)[cite: 2]
ช่วงกำลังไฟฟ้าที่ครอบคลุม 0.75 kW ถึง 500.0 kW (1.0 HP ถึง 700 HP)[cite: 2]
แรงดันไฟฟ้าขาเข้า 3 เฟส 208V ถึง 240V AC / 3 เฟส 380V ถึง 480V AC (50/60 Hz)[cite: 2]
ประสิทธิภาพการควบคุมมอเตอร์ Scalar (V/f) & Sensorless Vector Control (SLVC) สำหรับมอเตอร์ Induction, PM และ SynRM[cite: 2]
ความปลอดภัยทางฟังก์ชันและฮาร์มอนิก Safe Torque Off (STO SIL3 / PL e), ชอล์กแปรผันลดฮาร์มอนิกในตัว, ฟิลเตอร์ C2 EMC ในตัว[cite: 2]
การสื่อสารฟิลด์บัส Modbus RTU ในตัว; การ์ดออปชันเสริม PROFINET, EtherCAT, EtherNet/IP, PROFIBUS DP, CANopen[cite: 2]

ตารางการเลือกรุ่นไดรฟ์ ABB ACS580 ตามกำลังไฟฟ้าและขนาดเฟรม

ตารางการเลือกที่ครอบคลุมสำหรับอินเวอร์เตอร์เอนกประสงค์ ABB ACS580 ตรวจสอบกำลังมอเตอร์พิกัด กระแสเอาต์พุต สัญลักษณ์ขนาดเฟรม และรหัสสั่งซื้อมาตรฐาน:[cite: 2]

คู่มือการอัปเกรดจากไดรฟ์รุ่นเก่า ABB ACS550 / ACS510 เป็น ACS580

อินเวอร์เตอร์เอนกประสงค์รุ่นเก่าที่ยกเลิกการผลิตแล้วอย่าง ABB ACS550 และ ACS510 สามารถอัปเกรดเป็นไดรฟ์ ACS580 รุ่นปัจจุบันได้โดยตรง ด้วยขนาดตำแหน่งยึดเจาะที่ตรงกัน 100% พร้อมประสิทธิภาพการใช้พลังงานที่ดียิ่งขึ้น:[cite: 2]

รหัสไดรฟ์ ABB รุ่นเก่า (ยกเลิกการผลิต) กำลังไฟฟ้าและกระแสไฟรุ่นเก่า รุ่นเทียบเท่า ACS580 ปัจจุบัน การอัปเกรดและประสิทธิภาพหลักที่เพิ่มขึ้น
ACS550-01-03A3-4 / ACS510-01-03A3-4 1.1 kW / 3.3 A 400V ACS580-01-04A1-4 ยึดแทนตำแหน่งเดิมได้ 100% หน้าจอควบคุมผู้ช่วยที่ใช้งานง่ายพร้อมระบบปรับการใช้พลังงาน มีหน้าจอบลูทูธเป็นออปชันเสริม[cite: 2]
ACS550-01-012A-4 / ACS510-01-012A-4 5.5 kW / 12.0 A 400V ACS580-01-012A-4 ยึดแทนตำแหน่งเดิมได้ 100% ขนาดรูยึดน็อตตรงกันทุกประการ มีระบบความปลอดภัย STO SIL3/PL e ในตัว ฮาร์มอนิกต่ำลง[cite: 2]
ACS550-01-023A-4 / ACS510-01-023A-4 11.0 kW / 23.0 A 400V ACS580-01-026A-4 ยึดแทนตำแหน่งเดิมได้ 100% รองรับมอเตอร์ IE3, IE4 และ IE5 SynRM อย่างเต็มรูปแบบ รองรับการ์ดสื่อสารฟิลด์บัสแบบเสียบ[cite: 2]
ACS550-01-045A-4 / ACS510-01-045A-4 22.0 kW / 45.0 A 400V ACS580-01-045A-4 ยึดแทนตำแหน่งเดิมได้ 100% ใช้ทดแทนตำแหน่งเดิมได้โดยตรงสำหรับปั๊มอุตสาหกรรม พัดลม สายพานลำเลียง และคอมเพรสเซอร์[cite: 2]

คำแนะนำด้านการจัดหาทางวิศวกรรมและการบูรณาการระบบ

WE DRIVE HONGKONG LIMITED มีความเชี่ยวชาญในการจัดหาทางเทคนิค การระบุรหัสพาร์ตที่ถูกต้อง และการจัดส่งด่วนทั่วโลกสำหรับ **กลุ่มผลิตภัณฑ์อินเวอร์เตอร์เอนกประสงค์ ABB ACS580 ครบวงจร**[cite: 2] ไม่ว่าโรงงานของคุณจะต้องการไดรฟ์แบบติดผนัง (**ACS580-01**)[cite: 2] รุ่นกันน้ำ IP55 / UL Type 12 สำหรับสภาพแวดล้อมที่เปียกชื้น[cite: 2] โมดูลไดรฟ์สำหรับประกอบตู้คอนโทรล (**ACS580-04**)[cite: 2] หรือไดรฟ์ประกอบตู้สำเร็จรูป (**ACS580-07**)[cite: 2] อุปกรณ์ทั้งหมดสามารถจัดส่งได้พร้อมแผงควบคุมผู้ช่วย ชอล์กแปรผัน และฟิลเตอร์ EMC[cite: 2]

เมื่อต้องการเปลี่ยนทดแทน **อินเวอร์เตอร์รุ่นเก่าอย่าง ABB ACS550 หรือ ACS510** ในสถานประกอบการผลิต การเปลี่ยนมาใช้ไดรฟ์ ACS580 รุ่นปัจจุบันจะช่วยประหยัดพลังงานได้ทันที ลดการรบกวนของฮาร์มอนิก เพิ่มความปลอดภัยตามมาตรฐาน STO SIL3 และการเชื่อมต่อที่ราบรื่นกับเครือข่าย PLC สมัยใหม่[cite: 2] เพียงแจ้งรหัสป้ายชื่อไดรฟ์เดิมหรือซีเรียลนัมเบอร์ของคุณให้เราทราบ (เช่น *ACS550-01-045A-4* หรือ *ACS580-01-045A-4*) ทีมวิศวกรของเราจะส่งข้อเสนอและสเปกทดแทนที่ถูกต้อง 100% ให้คุณทันที[cite: 2]
