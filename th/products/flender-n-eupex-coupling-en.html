ยอยยาง Flender N-EUPEX Type A 160 Flexible Pin Coupling

แบรนด์: Flender GmbH | ซีรีส์: N-EUPEX & N-EUPEX DS Flexible Pin & Bush Couplings (ขนาด 58 ถึง 710)

Flender N-EUPEX Type A 160 เป็นยอยยางแบบ 3 ชิ้นส่วน (Flexible Pin & Bush Elastomer Coupling) ที่ได้รับความนิยมและมีการใช้งานแพร่หลายที่สุดในระบบส่งกำลังอุตสาหกรรมทั่วโลก ออกแบบทางวิศวกรรมเพื่อชดเชยการเยื้องศูนย์ของเพลา (แนวมุม แนวรัศมี และแนวแกน) พร้อมช่วยลดแรงสั่นสะเทือนจากการหมุนและรองรับแรงกระแทกได้อย่างมีประสิทธิภาพ โครงสร้างแบบ 3 ชิ้นส่วนของรุ่น Type A ช่วยให้สามารถเปลี่ยนยางยอย (Elastomer Packets) ได้โดยไม่ต้องเคลื่อนย้ายมอเตอร์หรือเครื่องจักรที่ต่ออยู่ มีให้เลือก 23 ขนาดมาตรฐาน (ขนาด 58 ถึง 710) รองรับแรงบิดปกติ ตั้งแต่ 19 Nm ถึง 85,000 Nm ยอย N-EUPEX ทำจากเหล็กหล่อคุณภาพสูงพร้อมชุดยางยอย NBR หรือ TPU ยืดหยุ่น ปลอดภัย มั่นใจได้ และถูกนำไปใช้งานอย่างแพร่หลายในปั๊ม พัดลม สายพานลำเลียง คอมเพรสเซอร์ โรงบด และเครื่องจักรเครนยก

ตารางโครงสร้างโมดูลาร์ยอยยาง Flender N-EUPEX ซีรีส์

คู่มือการกำหนดโครงสร้างแบบโมดูลาร์ฉบับสมบูรณ์สำหรับยอยยาง Flender N-EUPEX และ N-EUPEX DS Flexible Pin & Bush Couplings ตรวจสอบรูปแบบการใช้งาน ตัวเลือกจานเบรก สเปเซอร์สำหรับปั๊ม และระบบป้องกันภาระเกิน:

ประเภทและรูปแบบโครงสร้างยอย ช่วงขนาดเฟรมที่รองรับ พิกัดแรงบิดปกติ (Nm) จุดเด่นการใช้งาน & แอปพลิเคชันหลัก
N-EUPEX Type A (3 ชิ้นส่วน แบบ Fail-Safe) ขนาด 110 ถึง ขนาด 710 (17 ขนาด) 380 Nm - 85,000 Nm บำรุงรักษาง่าย (เปลี่ยนยางยอยได้โดยไม่ต้องถอดถอนมอเตอร์)
N-EUPEX Type B (2 ชิ้นส่วน แบบ Fail-Safe) ขนาด 58 ถึง ขนาด 710 (21 ขนาด) 19 Nm - 85,000 Nm มาตรฐานกะทัดรัด (ระยะ DBSE สั้นที่สุด ประหยัดพื้นที่)
N-EUPEX Type D / E (แบบต่อจานเบรก / ดรัมเบรก) ขนาด 80 ถึง ขนาด 710 (17 ขนาด) 60 Nm - 85,000 Nm ประกอบชุดเบรก (ต่อรวมจานเบรกหรือดรัมเบรกสำหรับกว้านยก)
N-EUPEX Type H / P (สเปเซอร์สำหรับงานปั๊ม) ขนาด 110 ถึง ขนาด 315 (10 ขนาด) 380 Nm - 15,000 Nm สเปเซอร์ปั๊ม ANSI/ISO (ช่วยให้ถอดซ่อมซีลปั๊มได้สะดวก)
N-EUPEX DS ซีรีส์ (แบบ Non-Fail-Safe) ขนาด 68 ถึง ขนาด 250 (11 ขนาด) 34 Nm - 8,000 Nm ตัดการส่งกำลังเมื่อเกินกำลัง (แยกการเชื่อมต่อเมื่อยางยอยขาดเพื่อเซฟเครื่องจักร)

คู่มือการเปลี่ยนทดแทนยอยเดิมและการอัปเกรดเป็น Flender N-EUPEX

ยอย EUPEX รุ่นเก่าหรือยอยยางแบบพินขนาดไม่มาตรฐานที่สึกหรอซึ่งติดตั้งบนปั๊ม พัดลม และเกียร์ สามารถเปลี่ยนทดแทนเป็นยอยยาง Flender N-EUPEX รุ่นปัจจุบันได้ทันที อ้างอิงตารางเปรียบเทียบการเปลี่ยนทดแทนแบบ 1-to-1 ด้านล่าง:

รุ่นยอยดั้งเดิม / ซีรีส์เดิม กลไกการส่งผ่านกำลัง รุ่น N-EUPEX ทดแทนปัจจุบัน ความสามารถรองรับแรงบิด ข้อแนะนำทางวิศวกรรมการเปลี่ยนทดแทน
EUPEX เดิม ขนาด 160 Type A Pin & Bush Elastomer N-EUPEX Type A 160 มาตรฐานปัจจุบัน 1,050 Nm ขนาดดุมและระยะรูน็อตตรงกันแบบ 1-to-1 ใช้ลูกยาง N-EUPEX มาตรฐาน
EUPEX เดิม ขนาด 160 Type B Pin & Bush Elastomer N-EUPEX Type B 160 มาตรฐานปัจจุบัน 1,050 Nm โครงสร้าง 2 ชิ้นส่วนกะทัดรัด ความลึกรูสวมเพลาเท่ากันทุกประการ
ยอยยางชนิด Jaw / Spider Couplings Elastomer Spider N-EUPEX Type B 110 / 140 / 160 งานหนัก 380 Nm - 1,050 Nm ทดแทนยอยสไปเดอร์ที่ชำรุดง่ายด้วยลูกยางยอย NBR ทนทานสูง
ยอยปั๊มอุตสาหกรรม ISO / ANSI Process Pump Pin & Bush Spacer N-EUPEX Type H / Type P Spacer งานปั๊ม 380 Nm - 15,000 Nm ระยะสเปเซอร์ DBSE มาตรฐาน (100mm, 140mm, 180mm, 250mm)
งานที่ต้องการตัดระบบเมื่อโหลดเกิน Fail-Safe Bushing N-EUPEX DS Type A / Type B Non-Fail-Safe 34 Nm - 8,000 Nm ตัดการส่งผ่านกำลังทันทีเมื่อลูกยางขาดเพื่อปกป้องเครื่องจักรราคาแพง

ข้อแนะนำวิศวกรรมการเลือกใช้งานและการสั่งกลึงเพลา

เรามีความเชี่ยวชาญในการจัดหาและบริการกลึงรูเพลาตามสั่งสำหรับ ยอยยาง Flender N-EUPEX และ N-EUPEX DS ทั้งหมด ไม่ว่าระบบส่งกำลังของคุณจะต้องการยอยแบบ 3 ชิ้นส่วนที่บำรุงรักษาง่าย (N-EUPEX Type A 110 ถึง 710), ยอยแบบ 2 ชิ้นส่วนขนาดกะทัดรัด (Type B 58 ถึง 710), ยอยต่อจานเบรกหรือดรัมเบรก (Type D / Type E), ชุดสเปเซอร์สำหรับปั๊ม (Type H / Type P) หรือยอยตัดระบบป้องกันเครื่องจักร (N-EUPEX DS) ดุมยอยทุกชิ้นสามารถสั่งกลึงรูเพลา เจาะร่องคีย์ ทำสโลป หรือทำเฟืองสเปไลน์ได้อย่างแม่นยำตามแบบวาดทางวิศวกรรม

สำหรับการซ่อมบำรุงเครื่องจักรเดิมที่ลูกยางยอยสึกหรอ เรามีสต็อก ยางยอย Flender N-EUPEX แท้ ครบทุกเกรด ได้แก่ ยาง NBR 80 Shore A มาตรฐาน, ยาง NBR 90 Shore A รับงานหนัก และยาง TPU ทนความร้อนสูง เพียงแจ้งขนาดยอย ขนาดรูเพลา และเงื่อนไขการใช้งาน ทีมวิศวกรของเราพร้อมเสนอสเปกที่ถูกต้อง 100%
