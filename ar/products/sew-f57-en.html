محرك جيربكس حلزوني ذو عمود متوازي SEW FA57DRN100L4

العلامة التجارية: SEW-Eurodrive | السلسلة: سلسلة FA (عمود متوازي مجوف)

يعد SEW FA57DRN100L4 محرك جيربكس حلزوني ذو عمود متوازي صناعي متين ومدمج يتميز بتصميم عمود مجوف (Hollow Shaft)[cite: 2]. تم تصميمه لتحقيق كفاءة ميكانيكية عالية، وسعة حرارية ممتازة، وتلبية متطلبات المساحات الضيقة، ويستخدم على نطاق واسع في خطوط نقل المواد، والخلاطات الصناعية، وآلات التغليف، ومحركات الأتمتة المصنع[cite: 2].

مصفوفة التكوين التجميعي SEW سلسلة F57

دليل التجميع التراكبي الشامل لصناديق التروس الحلزونية ذات العمود المتوازي SEW-Eurodrive مقاس 57[cite: 2]. استعرض خيارات التثبيت الميكانيكي المدعومة، واقترانات المحركات الحالية من IE1 إلى IE4، وخيارات الحماية المتاحة من المصنع:

تثبيت وحدة التروس / تصميم العمود مقاس الهيكل سلسلة المحركات المتوافقة والقدرات الملحقات الاختيارية من المصنع
FA57 (عمود مجوف مع مجرى خابور)[cite: 2] مقاس 57[cite: 2] سلسلة DRN (كفاءة IE3 ممتازة: من 71M4 إلى 112M4 / 0.37 إلى 4.0 كيلوواط)[cite: 2] /BE (فرامل قرصية للحماية عند انقطاع التيار)
F57 (عمود صلب مثبت بآرجل)[cite: 2] مقاس 57[cite: 2] سلسلة DRE (كفاءة عالية IE2)[cite: 2] /TF (حماية حرارية بحساس ثيرمستور PTC)
FF57 / FAF57 (تثبيت فلنجة B5)[cite: 2] مقاس 57[cite: 2] سلسلة DRS (كفاءة قياسية IE1)[cite: 2] /TH (مفتاح تحكم بلمس الثرموستات)
FAZ57 (تثبيت فلنجة وجهية B14)[cite: 2] مقاس 57[cite: 2] سلسلة DV / DT (محركات التحديث القديمة: DT71 إلى DV112)[cite: 2] /RS (مانع دوران عكسي ميكانيكي / باك ستوب)
FH57 / FHF57 / FHZ57 (قرص انكماش)[cite: 2] مقاس 57[cite: 2] سلسلة DFV / DFT (نسخ مضادة للانفجار معتمدة ATEX)[cite: 2] /V (مروحة تبريد إضافية قسرية)
FT57 / FTF57 / FTZ57 (جلبة تثبيت TorqLOC®)[cite: 2] مقاس 57[cite: 2] سلسلة CV / CT (مخصصة للعمل مع المغيرات والمحركات السيرفو)[cite: 2] /DH (تصريف تكثيف مخصص للظروف القاسية)

دليل استبدال محركات SEW القديمة والترقية إلى IE3 DRN

محركات SEW القديمة المتوقفة عن الإنتاج (DT و DV و DRS و DRE) المثبتة على جيربكس F57 يمكن استبدالها بسلاسة بمحركات DRN الحديثة ذات الكفاءة الممتازة IE3. يرجى الرجوع إلى جدول المطابقة المباشرة أدناه للاستبدال 1 إلى 1:

رمز المحرك القديم (متوقف) مستوى الكفاءة المحرك البديل الحالي IE3 القدرة الاسمية (kW) التوافق الميكانيكي وملاحظات الاستبدال
DT71D4 / DV71D4 IE1 / كفاءة قياسية DRN71M4 ترقية IE3 0.37 - 0.55 كيلوواط تطابق مباشر 1 إلى 1 للفلنجة والعمود على جيربكس F57. تقليل الفقد في الطاقة.
DT80N4 / DV80N4 IE1 / كفاءة قياسية DRN80M4 ترقية IE3 0.75 كيلوواط أبعاد التثبيت متطابقة تماماً؛ استبدال مباشر دون تعديل.
DT90S4 / DV90S4 IE1 / كفاءة قياسية DRN90S4 ترقية IE3 1.1 كيلوواط أبعاد الفلنجة والعمود متطابقة. يرجى التحقق من موضع صندوق التوصيل.
DT90L4 / DV90L4[cite: 2] IE1 / كفاءة قياسية[cite: 2] DRN90L4 ترقية IE3[cite: 2] 1.5 - 2.2 كيلوواط تم الحفاظ على التوافق مع محولات B5/B14. متوافق تماماً مع معايير IE3 الحديثة.
DV100M4 / DRE100M4 كفاءة IE1 / IE2 DRN100LS4 ترقية IE3 2.2 - 3.0 كيلوواط استبدال مباشر على وحدات التروس F57 و FA57 و FAF57 و FH57.
DV100L4 / DRE100L4[cite: 2] كفاءة IE1 / IE2[cite: 2] DRN100L4 ترقية IE3[cite: 2] 3.0 - 4.0 كيلوواط[cite: 2] الاقتران القياسي لموديل FA57. يستبدل المحرك القديم DV100L4 بسلاسة[cite: 2].
DV112M4 / DRE112M4[cite: 2] كفاءة IE1 / IE2[cite: 2] DRN112M4 ترقية IE3[cite: 2] 4.0 - 5.5 كيلوواط ارتفاع محور العمود ونمط الثقوب متطابقان تماماً. يتوفر خيار الفرامل BE2/BE5.
DV132S4 / DRE132S4 كفاءة IE1 / IE2 DRN132S4 ترقية IE3 5.5 - 7.5 كيلوواط[cite: 2] أقصى سعة قدرة لسلسلة F57. وحدة استبدال جاهزة للتطبيقات الثقيلة.

ملاحظات الهندسة والاختيار المتخصص

نحن متخصصون في تقديم حلول محركات كاملة وحلول استبدال فنية لجميع موديلات SEW-Eurodrive سلسلة F57[cite: 2]. سواء كنت بحاجة إلى وحدة مثبتة بآرجل وعمود صلب (F57)[cite: 2]، أو عمود مجوف مع مجرى خابور (FA57)[cite: 2]، أو فلنجة خرج B5 (FAF57 / FF57)[cite: 2]، أو اتصال بقرص انكماش (FH57)[cite: 2]، أو نظام تثبيت TorqLOC® بدون خابور (FT57)[cite: 2]، يمكن توريد جميع التصاميم الميكانيكية مجمعة مسبقاً مع محركات سلسلة DRN (من DRN71M4 إلى DRN112M4) فائقة التطور بامتياز IE3[cite: 2].

عند تحديث تطبيق حالي يعمل بمحرك قديم متوقف مثل DT71 أو DT80 أو DT90 أو DV100 أو DV112[cite: 2]، فإن الترقية إلى محرك IE3 DRN تضمن توافقاً أبعادياً بنسبة 100% مع خفض درجات حرارة التشغيل وتكاليف الطاقة بشكل كبير. فقط أرسل لنا الرقم التسلسلي الحالي لـ SEW أو كود اللوحة المعدنية (بما في ذلك خيارات مثل فرامل BE أو حساس TF أو مانع الدوران العكسي RS)، وسيقوم فريقنا الهندسي بتزويدك بالمواصفات البديلة والعرض السعري المتوافق تماماً.
