Пневматические регулирующие клапаны Samson Type 3251 для тяжелых условий эксплуатации

Бреند: SAMSON AG | Категория: Проходные регулирующие клапаны высокого давления и для тяжелых условий (Размеры: DN 15–DN 500 | Давление: до PN 400 / ASME Class 2500)

Серия регулирующих клапанов Samson Type 3251 для тяжелых условий эксплуатации (severe service) (базовая модель: Type 3251 DN 50 Class 600 с приводом Type 3271) — это флагманская платформа SAMSON AG, спроектированная специально для сложных условий процессов, сверхвысоких перепадов давления, вскипания жидкостей, кавитационных потоков и высокотемпературных паровых контуров на НПЗ, нефтехимических производствах, байпасных станциях турбин ТЭЦ и офшорных газовых комплексах. Клапаны изготавливаются с толстостенными литыми (1.0619 / A216 WCB), высокотемпературными легированными (1.7335 / A217 WC6), нержавеющими (1.4408 / A351 CF8M) или коваными корпусами и оснащаются **разгруженными по давлению затворами повышенной прочности**, антикавитационными клетками (AC-1 / AC-2 / AC-3) и дросселирующими элементами с наплавкой стеллитом или карбидом вольфрама. Для предотвращения утечек токсичных газов или потерь пара высокого давления клапан может комплектоваться изолирующей вставкой или **двухслойным сильфонным уплотнением из нержавеющей стали**. Клапаны приводятся в действие мощными **пневматическими мембранными приводами Type 3271 или Type 3277** и цифровыми **позиционерами Type 3730**, обеспечивая точное регулирование потока, герметичность закрытия (Class IV–VI) и надежное снижение уровня шума в диапазоне размеров от **DN 15 до DN 500 (1/2"–20")** с коэффициентом Kvs от **0,1 до 3150**. WE DRIVE HONGKONG LIMITED обеспечивает технический подбор, расчет Kvs для тяжелых условий, подбор антикавитационных клеток и экспресс-поставку регулирующих клапанов Samson Type 3251 по всему миру.
