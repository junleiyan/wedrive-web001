Busch Vacuum Pumps - Type Designation

The following example shows the structure of the modular Busch type designation:

Example: R5 RA 0250 D
R5 Busch Product Series (e.g., R5 = Rotary Vane, MINK = Claw, COBRA = Dry Screw)
RA Design Version / Application:
  • RA = Standard robust version
  • PB = Compact block version
  • RC = Designed for specific rough vacuum tasks
0250 Nominal Pumping Speed: Indicates the flow rate in m³/h (e.g., 250 m³/h)
D Generation / Variant Code:
  • F, D, B, C = Indicates the evolutionary design generation or mechanical revision
